MacAppControlDeck 安装说明

如果你收到的是 zip 压缩包：先双击解压，得到一个文件夹，
里面有 MacAppControlDeck.app、安装脚本和本说明。

第 1 步：双击「安装 MacAppControlDeck.command」。
        如果提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」，
        请右键点它 -> 打开 -> 再点「打开」。

第 2 步：等它自动完成。装好后会自动打开「设置 - 桌面宠物」，
        并弹窗告诉你结果；任何一步出问题都会弹窗说明原因。

装好之后怎么用：
  - 这个 App 不会出现在 Dock，也没有主窗口，它常驻在屏幕右上角的菜单栏。
  - 菜单栏图标是「三条横线加一个圆点」。
  - 第一次启动会自动出现桌面宠物（一只趴在键盘前的猫）。
  - 装完后脚本会自动打开「设置 - 桌面宠物」，可以在那里调大小和皮肤。
  - 如果设置窗口没打开：点菜单栏图标 -> 设置… -> 桌面宠物。

常见问题：
  - 双击有「已损坏，无法打开」提示：对 App 右键 -> 打开 -> 打开。
  - 弹窗提示芯片不匹配：向发送人索要对应芯片的安装包
    （Apple 芯片要 arm64，Intel 芯片要 x86_64）。
  - 需要看详细过程：安装脚本会把日志写到 /tmp/deck-install.log

卸载：
  把「应用程序」里的 MacAppControlDeck.app 拖到废纸篓。
