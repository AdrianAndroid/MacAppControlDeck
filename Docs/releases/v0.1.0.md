# v0.1.0 · 首个可下载版本

发布日期：2026-11-20

MacAppControlDeck 的第一个公开构建。它是一个只常驻菜单栏的 macOS 工具：在同一局域网内用手机浏览器遥控 Mac 应用，同时在本机提供截图、标注、录屏和 GIF 能力。

## 下载

| 芯片 | 安装包 | 大小 |
|---|---|---|
| Apple Silicon（M1/M2/M3/M4） | `MacAppControlDeck-0.1.0-arm64.dmg` | 约 3.5 MB |
| Intel（x86_64） | `MacAppControlDeck-0.1.0-x86_64.dmg` | 约 3.8 MB |

同时提供 `.zip` 压缩包，内容与 DMG 中的 `.app` 相同。全部资产见 `SHA256SUMS.txt`。

确认芯片：苹果菜单 →「关于本机」，或终端执行 `uname -m`（`arm64` / `x86_64`）。

## 安装

1. 打开对应 DMG，把 `MacAppControlDeck.app` 拖入「应用程序」。
2. 首次启动如被 Gatekeeper 拦截：右键应用 →「打开」，或执行
   `xattr -dr com.apple.quarantine /Applications/MacAppControlDeck.app`。
3. 按首次配置授予「辅助功能」（跨桌面切换）和「屏幕录制」（截图/录屏）权限，然后重启应用。

本版使用 ad-hoc 签名，**未经过 Apple 公证**，因此首次打开会有安全提示。没有自动更新，后续版本需手动下载覆盖。

## 本版内容

- 菜单栏按模块组织：置顶命令直接平铺在一级菜单，点开即用
- 「电脑控制」模块：应用启动/激活、跨桌面切换、快捷操作、手机配对与面板
- 「截图与录屏」模块：全屏/区域/窗口/滚动截图，标注编辑器，OCR，钉图，MP4/GIF 录制，视频剪辑
- 手机面板：局域网内配对，按钮列表 5 秒刷新；断网恢复后自动重连
- 设置页：菜单定制、置顶顺序调整、按钮/设备管理、模块独立开关

## 系统要求

- macOS 14 Sonoma 及以上
- 手机与 Mac 在同一局域网
- 电脑遥控需「辅助功能」；截图/录屏需「屏幕录制」

## 已知限制

- 未公证、未接入 Sparkle 自动更新
- 通信为局域网明文 HTTP，请只在可信网络使用
- Snipaste 等注册系统级热键的应用请使用「命令按钮」触发
- 滚动截图遇到固定侧栏/工具栏时可能出现重复区域
