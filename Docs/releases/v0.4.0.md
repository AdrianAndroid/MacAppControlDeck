# v0.4.0 · 自动升级

2026-11-24

## 新增

- **自动升级**：内置 Sparkle 2，从 GitHub Releases 的 `appcast.xml` 检查、下载并安装新版本。
  - 菜单栏「检查更新…」、设置 →「通用 → 更新」、内置操作「检查更新」三处入口
  - 默认每天后台检查一次；下载完成后由用户确认重启才替换
  - 更新包必须带 EdDSA 签名（公钥内置 `SUPublicEDKey`），且与本机 App 同一固定自签名证书，否则拒绝升级
  - 升级后辅助功能 / 输入监控 / 屏幕录制 / 自动化授权保持有效，不用重新授权
- **universal 单包**：`package-release.sh universal` 用 lipo 合并 arm64 + x86_64，appcast 只登记一条记录
- **GitHub Actions 发版**：推送 `v*` 标签后自动构建、签名、生成 appcast 并发布 Release

## 变更

- `Build/Info.plist`：`CFBundleShortVersionString` 0.3.1 → 0.4.0，`CFBundleVersion` 4 → 6
- 构建脚本统一嵌入并重签 `Sparkle.framework`（`Contents/Frameworks` + `@executable_path/../Frameworks`）
- Release 资产改为 `-universal.dmg` / `-universal-installer.zip` / `-universal.zip` / `appcast.xml` / `SHA256SUMS.txt`

## 升级方式

装 v0.4.0 之后，后续版本都可以在 App 内完成；首次仍需手动安装一次（包未公证，右键「打开」）。

## 已知限制

- 更新包不做增量（每次下完整 universal ZIP，约 19 MB）
- 不接入 Apple 公证 / Developer ID，首次安装仍需右键打开
- GitHub 直连不稳定时检查会静默失败；可用 `DECK_UPDATE_FEED` 指向镜像
