# v0.4.2 · 按钮管理卡片网格与副屏/钉图改进

2026-11-26

本版本承接 v0.4.1，把按钮管理从纵向列表重做为 4 列卡片网格，并合入副屏桌宠、截图钉图原位、状态栏日历等一批改进。

## 新增

- **按钮管理 4 列卡片网格**：应用与快捷操作分组展示，分组标题吸顶、可折叠；按钮超过 12 个时出现搜索框，可按名称、Bundle ID、快捷键或类型过滤。
  - 点击卡片只做高亮选中，不执行按钮本身；底部不再出现「已选 xxx / 重命名 / 删除」选中操作条。
  - 按住 0.5 秒进入拖动准备态，继续移动超过 4pt 才开始排序；拖动期间浮层持续跟随指针，目标位置显示虚线插入空隙，松手只落盘一次。
  - 右键卡片提供「重命名…」「编辑组合…」（仅快捷操作）、「上移」「下移」「删除…」；删除有二次确认。
  - 应用与快捷操作各自组内排序，不跨组混排；搜索状态禁止拖拽。
- **状态栏日历**：菜单栏新增日历图标，点击弹出深色玻璃月历面板（周日首列 / 农历节气 / 今日蓝框 / 节日休班标记，不读 EventKit）。
- **副屏桌宠与底栏**：副屏横屏三栏布局，桌宠框 / 下班倒计时 / 天气信息同高同基线；支持像素猫 / 小狗 / 机器人本地换宠、固定或随机切换；去掉桌宠内层背景与边框，只保留一层外框。
- **桌宠底部快捷栏**：桌宠下方半透明胶囊，只放手机 Deck 的应用按钮；运行中应用带绿点，按点击频率排序，长按横向拖动滚动。
- **截图钉图原位**：区域截图钉图落在原截图位置，跨屏保持原尺寸与选区中心；历史/剪贴板/编辑器来源仍居中。

## 变更

- **副屏控制条**：刷新/全屏控制条从底部移到顶部，显示后 5 秒自动隐藏（含触屏），轻点屏幕任意处可再次唤出；点「↻」执行整页重载。
- **副屏设置统一到 Mac 端**：控制条只保留强制刷新与全屏；尺寸 / 桌宠 / 常亮改在「设置 → 副屏」配置；副屏 HTML 抽为资源文件，改页面重新构建从约 6.5 分钟降到约 4 秒。
- **状态栏拆分**：CPU / MEM / 网速拆成三个独立状态项，可分别点击、单独勾选显示，位置支持 ⌘-拖持久化；无权限时整块隐藏，避免半截结果。
- **UI 草图资源与提示**：修复 SwiftPM `Contents/Resources/<bundle>/Sketch` 资源定位；阻塞式提示改为非模态浮动窗，不再卡住菜单栏与 F1 截图。
- **构建适配**：适配 macOS 27 SDK 与 Sparkle.framework 路径；`package-release.sh` 统一使用 `--disable-sandbox` 并保留真实编译错误输出。

## 构建与升级

- `Build/Info.plist`：`CFBundleShortVersionString` 0.4.1 → 0.4.2，`CFBundleVersion` 7 → 8。
- 本机 `./Build/publish-local.sh` 构建 universal（Apple Silicon + Intel）单包，固定签名 `MacAppControlDeck Self-Signed`，EdDSA 签名 appcast，并上传 5 个资产到 GitHub Release。
- **不轮换 `SUPublicEDKey`**：v0.4.1 存量客户端的 Sparkle 升级链保持有效；升级后辅助功能 / 输入监控 / 屏幕录制 / 自动化授权不失效。
- 发布资产：`MacAppControlDeck-0.4.2-universal.dmg`、`...-installer.zip`、`...-universal.zip`、`appcast.xml`、`SHA256SUMS.txt`。

## 已知限制

- 更新包不做增量，每次下载完整 universal ZIP；不接入 Apple 公证，首次安装仍需右键「打开」。
- 长按拖动第一版不做边缘自动滚动；按钮很多时需先滚动到目标区域再拖。
- 副屏天气依赖和风账号 API Key，升级后可能需重新粘贴一次。
