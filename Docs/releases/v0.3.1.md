# v0.3.1 · 移除 v5 冗余资源，安装包 51 MB → 15 MB

发布日期：2026-11-22

本版不改变用户可见行为，只做运行时与资源清理：删除已弃用的 v5 桌宠分层运行时和 35 MB 全画布 PNG 资源，桌宠回退链固定为 `v6 → v4 → 矢量`。同时修复发布脚本复用 SwiftPM 旧资源缓存的问题，避免已删除资源再次被打进安装包。

## 下载

| 芯片 | 安装包 | 大小 |
|---|---|---|
| Apple Silicon（M1/M2/M3/M4） | `MacAppControlDeck-0.3.1-arm64.dmg` | 约 15 MB |
| Intel（x86_64） | `MacAppControlDeck-0.3.1-x86_64.dmg` | 约 15 MB |

同时提供 `.zip` 压缩包，内容与 DMG 中的 `.app` 相同。全部资产见 `SHA256SUMS.txt`。

确认芯片：苹果菜单 →「关于本机」，或终端执行 `uname -m`（`arm64` / `x86_64`）。

## 安装

1. 打开对应 DMG，把 `MacAppControlDeck.app` 拖入「应用程序」。
2. 首次启动如被 Gatekeeper 拦截：右键应用 →「打开」，或执行
   `xattr -dr com.apple.quarantine /Applications/MacAppControlDeck.app`。
3. 按首次配置授予「辅助功能」「输入监控」和「屏幕录制」权限，然后重启应用。

本版继续使用固定身份 `MacAppControlDeck Self-Signed`（SHA-1 `E83574620FE6CF96BA5A9C902F8B6A5C38F5A6B3`），**未经过 Apple 公证**。从 0.3.0 覆盖升级时签名身份不变，已有 TCC 授权可继续匹配。

## 本版内容

### 体积清理

- 删除 `Sources/MacAppControlDeck/Modules/Pet/Resources/v5/`，约 35 MB；v5 的 12 张 1440×1920 全画布 PNG 单张约 2.7 MB，多数图层可见像素不足 2%
- 删除 `PetRasterV5.swift`、`Package.swift` 中的 v5 资源声明及 `PetV5RigTests.swift`
- 桌宠渲染回退链改为 `v6 → v4 → 矢量`；v5 原本只在 v6 缺失时才会命中，发布包始终带 v6，实际不可达
- `.app` 从 62 MB 降到 27 MB；DMG 从 50.6 MB 降到约 15 MB；ZIP 从 50.8 MB 降到约 14 MB

### 验证与测试

- 新增 `PetRasterStateTests`，保留 idle、眨眼、左右爪分区、真实键帽位置和头部偏航上限等通用状态机测试
- `swift test` 共 103 项、101 通过；2 个既有 `PetPanelControllerTests` 窗口尺寸断言失败与本版无关，已记录为已知限制
- `swift build -c release`、`./Build/build.sh` 均通过
- 打包后的 DMG 已挂载复核：两个架构均为 27 MB `.app`，包内不存在任何 `v5` 目录

### 打包与签名

- `Build/package-release.sh` 在构建前执行 `swift package clean --scratch-path`，防止 SwiftPM 资源 bundle 保留已删除的 v5 并重新带入安装包
- 两个架构均通过 `./Build/verify-signing.sh`，designated requirement 稳定为 `identifier "com.zhaojian.MacAppControlDeck" and certificate root = H"e83574620fe6cf96ba5a9c902f8b6a5c38f5a6b3"`

## 已知限制

- **真实 iPhone Safari 手测仍未执行**：本机没有真实 iPhone，面板的长按/双击/拖动禁用与配对页软键盘继续依赖 Chrome CDP 多尺寸验证
- **BongoCat 键位高亮未重映射**：按住字母键时蓝色高亮/猫爪落点仍可能与键盘透视的键帽位置有偏差
- 2 个 `PetPanelControllerTests` 窗口尺寸断言在本机屏幕下失败，属于既有测试期望值与实际窗口尺寸差异
- 未公证、未接入 Sparkle 自动更新；后续版本需手动下载覆盖
- 通信为局域网明文 HTTP，请只在可信网络使用
