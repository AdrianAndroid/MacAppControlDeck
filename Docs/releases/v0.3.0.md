# v0.3.0 · 手机面板横竖屏自适应 + 固定签名

发布日期：2026-11-22

本版把手机控制面板重做为真正的自适应布局：竖屏继续「上应用、下快捷」，横屏改成「左应用、右快捷」，右侧 8 个快捷按钮全部是正方形；整页锁定视口，只保留横向翻页，旋转后保持当前页。同时，发布包开始使用固定自签名身份，重建不再反复重置 TCC 授权。

## 下载

| 芯片 | 安装包 | 大小 |
|---|---|---|
| Apple Silicon（M1/M2/M3/M4） | `MacAppControlDeck-0.3.0-arm64.dmg` | 约 51 MB |
| Intel（x86_64） | `MacAppControlDeck-0.3.0-x86_64.dmg` | 约 51 MB |

同时提供 `.zip` 压缩包，内容与 DMG 中的 `.app` 相同。全部资产见 `SHA256SUMS.txt`。

确认芯片：苹果菜单 →「关于本机」，或终端执行 `uname -m`（`arm64` / `x86_64`）。

## 安装

1. 打开对应 DMG，把 `MacAppControlDeck.app` 拖入「应用程序」。
2. 首次启动如被 Gatekeeper 拦截：右键应用 →「打开」，或执行
   `xattr -dr com.apple.quarantine /Applications/MacAppControlDeck.app`。
3. 按首次配置授予「辅助功能」「输入监控」和「屏幕录制」权限，然后重启应用。

本版使用固定身份 `MacAppControlDeck Self-Signed`（SHA-1 `E83574620FE6CF96BA5A9C902F8B6A5C38F5A6B3`），**未经过 Apple 公证**。从 v0.2.0 的 ad-hoc 包升级时，系统会把签名身份变化视为新应用，TCC 授权需要重新授予一次；之后同一身份重建不再反复失效。

## 本版内容

### 手机面板

- **竖屏**：应用 2 列、行数按可用高度动态计算；底部快捷操作固定 4 列 × 2 行，每页 8 个
- **横屏**：左侧应用 4 列；右侧快捷栏 2 列 × 4 行正方形按钮，栏宽由 4 行按钮反推，不再贴底挤压应用区
- **视口锁定**：禁止整页纵向滚动、回弹、下拉刷新、按钮拖拽、长按菜单、文本选择和双击缩放
- **翻页与旋转**：应用区、快捷区各自横向 scroll-snap；页点可直接跳到对应页；旋转或窗口变化后保持页索引
- **尺寸适配**：`--u` + `clamp()` 流式缩放，极矮横屏进入紧凑档，宽屏最大宽度 1280px 居中
- 面板版本 `2026-11-22.2`，旧面板会通过 `/api/panel-version` 自动刷新

### 签名与文档

- 本机构建与本地发布包统一走 `Build/signing.sh` 的固定自签名，签名缺失直接失败，不静默退回 ad-hoc
- designated requirement 固定为 `identifier "com.zhaojian.MacAppControlDeck" and certificate root = H"e83574620fe6cf96ba5a9c902f8b6a5c38f5a6b3"`，辅助功能 / 输入监控 / 屏幕录制 / 自动化授权可跨重建保持
- README 更新为当前 BongoCat standard 透明桌宠、横竖屏面板实拍图、111 项测试现状与最新项目结构
- 新增面板实施记录与 OpenSpec 归档：`adaptive-remote-panel-layout`

### 桌面宠物

沿用 v0.2.0 的 BongoCat **standard** 透明键鼠场景：白猫、圆角鼠标垫、完整键盘，无白桌托板；保留键盘/鼠标左右键响应、光标视线跟随、三档尺寸、按轮廓点击穿透与隐藏即释放资源。

## 已知限制

- **真实 iPhone Safari 手测未执行**：长按/双击/拖动禁用与配对页软键盘已在 Chrome CDP 多尺寸验证，但本机没有真实 iPhone，Safari 真机回归留到 v0.3.1
- **BongoCat 键位高亮未重映射**：按住字母键时蓝色高亮/猫爪落点可能与新键盘透视的键帽位置有偏差
- 面板只支持横向翻页，不做纵向滚动；极窄横屏会优先保证按钮为正方形并减少可见行数
- 未公证、未接入 Sparkle 自动更新；后续版本需手动下载覆盖
- 通信为局域网明文 HTTP，请只在可信网络使用
