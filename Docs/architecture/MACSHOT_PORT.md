# macshot 能力移植对照（capture 模块）

> 上游：<https://github.com/sw33tLie/macshot>（GPL-3.0）
> 本地源码：`Sources/MacShotKit/`
> 边界：只属于 `capture` 模块，Mac 本机使用；不注册 HTTP，不出现在手机面板。

## 已移植（P1–P7）

### P1 标注对象与变换

- 选择工具：点击选中任意标注，拖动移动，8 向手柄缩放，Delete 删除
- 对象命中测试包含旋转后的边界，缩放快照避免累积误差
- 属性修改实时作用于当前选中对象；可双击文字重新编辑

### P2 高级标注样式

- 箭头 5 种：单线、加粗、双向、开口、燕尾；支持反向
- 矩形/椭圆 3 种填充：描边、填充、描边+填充；矩形圆角
- 富文本：粗体 / 斜体 / 下划线 / 删除线 / 左中右对齐 / 文字底色
- 旋转手柄，Shift 吸附 90°

### P3 钉图

- 静止时不显示任何按钮（符合用户明确要求）
- 悬停显示编辑 / 关闭；右键菜单：复制、另存为、关闭
- 缩放 0.1–5x：滚轮 / 捏合，以窗口中心缩放；百分比标签实时更新
- 点击百分比复位 100%；Esc 关闭
- 默认保存 `~/Pictures/MacAppControlDeck/Pinned yyyy-MM-dd HH.mm.ss.png`

### P4 麦克风与视频编辑器

- 录屏可同时采集系统音频与麦克风旁白（ScreenCaptureKit，macOS 15+ 守卫）
- 首次录制请求麦克风权限；拒绝时提示且不开始录制
- 录制完成自动打开视频编辑器：起点/终点双滑杆、系统声音/麦克风旁白开关、在 Finder 显示、另存为 MP4
- 导出使用 AVMutableComposition + AVAssetExportSession（最高质量）

### P5 取色 / 放大镜 / 印章 / QR

- 取色器直接读取 CGImage 像素，左上角显示 `R… G… B… #HEX`，点击复制 HEX
- 放大镜 2x–4x 倍率，圆形放大视图
- Emoji 印章（21 个内置），随字号缩放
- Vision 二维码/条形码识别：qr / code128 / code39 / ean13 / ean8 / pdf417 / aztec / dataMatrix

### P6 图像效果与 Beautify

- 滤镜预设：none / noir / mono / sepia / chrome / fade / instant / vivid
- 亮度 / 对比度 / 饱和度 / 锐度滑杆，编辑器画布实时预览
- Beautify：留白、圆角、阴影、6 种渐变背景；导出生效
- 导出链：标注 → 滤镜 → Beautify → 缩放

### P7 分辨率 / 边界吸附 / 多屏

- 编辑器“尺寸”预设：原始、1920×1080、1440×1080、1080×1080、1080×1920、2560×1440
- 区域选择边界吸附：12pt 内优先吸附屏幕边缘与可见窗口边界，其次像素强边缘；按住 Option 临时关闭
- 多屏：菜单“全屏截图（全部显示器拼接）”按显示器实际位置 1x 拼接为一张图
- 钉图、标注、保存、录屏等功能仍按单屏/单窗口工作

## 截图 / 录屏基础能力

- 全屏 / 区域 / 窗口截图；滚动截图；快速保存；快速 OCR；延时 0/3/5/10/30 秒
- 截图历史最近 12 条；PNG / JPEG / HEIC / WebP / AVIF；质量滑块
- MP4（H.264，15/30/60/120fps）+ GIF（5/10/15fps）；区域/全屏/窗口录制
- HUD：164×32、10pt 圆角、暂停/继续/停止；菜单栏可停止
- OCR：Vision 中英文，结果窗口可复制

## 仍未移植（有意排除或受平台限制）

| 能力 | 原因 |
|---|---|
| 注册 / 登录 / 账号体系 | 用户明确不移植 |
| Sparkle 自动更新 | 用户明确不移植；由本仓库自行构建安装 |
| Google Drive / imgbb / S3 上传 | 需要账号、密钥或外部服务 |
| 翻译 30+ 语言 | 依赖在线服务 |
| 鼠标点击高亮 / 录制选区边框 | 未接入事件监听覆盖层 |
| 自动 PII / 人脸打码 | 需要额外 Vision 模型与规则，保留手动打码 |
| 添加截图 / 粘贴图片图层 / 0.1–8x 画布缩放 | 当前单图编辑，无图层模型 |
| 100+ 分类 Emoji / 自定义图片印章 | 当前 21 个内置 Emoji |
| macOS 窗口框 / 交通灯 / 30 种渐变 / mesh 渐变 | Beautify 当前 6 种渐变，无窗口框素材 |
| 跨屏拖选区域并拼接 | 当前为“全部显示器整屏拼接”；跨屏拖选未接入 |
| Liquid Glass（macOS 26） | 本机 macOS 15，不引入仅 macOS 26 API |
