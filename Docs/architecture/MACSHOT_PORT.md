# macshot 能力移植对照（capture 模块）

> 上游：<https://github.com/sw33tLie/macshot>（GPL-3.0）
> 对比基线：本机已安装的 macshot Offline 4.4.0；上游源码 HEAD 4.5.0-beta.2
> 本地源码：`Sources/MacShotKit/`
> 边界：只属于 `capture` 模块，Mac 本机使用；不注册 HTTP，不出现在手机面板。

## 已移植（P1–P7）

### P1 标注对象与变换

- 选择工具：点击选中任意标注，拖动移动，8 向手柄缩放，Delete 删除
- 对象命中测试包含旋转后的边界，缩放快照避免累积误差
- 属性修改实时作用于当前选中对象；可双击文字重新编辑

### P2 高级标注样式

- 箭头 5 种：单线、加粗、双向、开口、燕尾；支持反向
- 矩形/椭圆 3 种填充：描边、填充、描边+填充；矩形圆角
- 富文本：粗体 / 斜体 / 下划线 / 删除线 / 左中右对齐 / 文字底色
- 旋转手柄，Shift 吸附 90°

### P3 钉图

- 静止时不显示任何按钮（符合用户明确要求）
- 悬停显示编辑 / 关闭；右键菜单：复制、另存为、关闭
- 缩放 0.1–5x：滚轮 / 捏合，以窗口中心缩放；百分比标签实时更新
- 点击百分比复位 100%；Esc 关闭
- 默认保存 `~/Pictures/MacAppControlDeck/Pinned yyyy-MM-dd HH.mm.ss.png`

### P4 麦克风与视频编辑器

- 录屏可同时采集系统音频与麦克风旁白（ScreenCaptureKit，macOS 15+ 守卫）
- 首次录制请求麦克风权限；拒绝时提示且不开始录制
- 录制完成自动打开视频编辑器：起点/终点双滑杆、系统声音/麦克风旁白开关、在 Finder 显示、另存为 MP4
- 导出使用 AVMutableComposition + AVAssetExportSession（最高质量）

### P5 取色 / 放大镜 / 印章 / QR

- 取色器直接读取 CGImage 像素，左上角显示 `R… G… B… #HEX`，点击复制 HEX
- 放大镜 2x–4x 倍率，圆形放大视图
- Emoji 印章（21 个内置），随字号缩放
- Vision 二维码/条形码识别：qr / code128 / code39 / ean13 / ean8 / pdf417 / aztec / dataMatrix

### P6 图像效果与 Beautify

- 滤镜预设：none / noir / mono / sepia / chrome / fade / instant / vivid
- 亮度 / 对比度 / 饱和度 / 锐度滑杆，编辑器画布实时预览
- Beautify：留白、圆角、阴影、6 种渐变背景；导出生效
- 导出链：标注 → 滤镜 → Beautify → 缩放

### P7 分辨率 / 边界吸附 / 多屏

- 编辑器“尺寸”预设：原始、1920×1080、1440×1080、1080×1080、1080×1920、2560×1440
- 区域选择边界吸附：12pt 内优先吸附屏幕边缘与可见窗口边界，其次像素强边缘；按住 Option 临时关闭
- 多屏：菜单“全屏截图（全部显示器拼接）”按显示器实际位置 1x 拼接为一张图
- 钉图、标注、保存、录屏等功能仍按单屏/单窗口工作

### P8 交互与最后一公里

- 全局快捷键（Carbon）：⌘⇧X 区域、⌘⇧F 全屏、⌘⇧W 窗口、⌘⇧S 滚动、⌘⇧R 录制、⌘⇧O 快速 OCR、⌘⇧E 重新编辑最近截图
- 两段式区域选择：统一全桌面遮罩，支持跨屏拖选；松开后可移动、拖 8 个手柄缩放；Enter 确认、Tab 循环比例、Esc 取消
- 选区预设：自由、1:1、4:3、16:9、21:9、3:2、9:16、720×480、1080×1080、1080×1920；菜单「选区比例 / 尺寸」可切换
- 编辑器键盘：Delete 删除、⌘C 复制、⌘S 保存、⌘Z/⌘⇧Z 撤销重做、⌘0 重置缩放、⌘+/⌘- 缩放
- 编辑器画布 0.1–8x 缩放（菜单与触控板捏合）；选中标注出现旋转手柄，拖拽旋转、按住 Shift 吸附 90°
- 添加图片（文件选择）与粘贴剪贴板图片，作为可拖动/缩放的图片图层
- 保存时记录原图 + 标注 JSON 到 `~/Library/Application Support/MacAppControlDeck/EditSessions`，菜单/⌘⇧E 可重新编辑
- 打码模式：马赛克 / 纯色覆盖 / 智能擦除（周边均值填充）
- 文字描边；编号 1/I/a/A 格式；测量 px/pt 切换；聚光灯压暗强度
- 常用颜色调色板；反色滤镜；Beautify 24+6 种渐变与窗口标题栏
- 导出 Retina 1x / 2x；OCR 使用 Vision 支持的全部语言
- 录屏：选区边框、鼠标点击黄色涟漪、逐轨系统/麦克风音量
- 视频编辑器逐轨音量导出

## 截图 / 录屏基础能力

- 全屏 / 区域 / 窗口截图；滚动截图；快速保存；快速 OCR；延时 0/3/5/10/30 秒
- 截图历史最近 12 条；PNG / JPEG / HEIC / WebP / AVIF；质量滑块
- MP4（H.264，15/30/60/120fps）+ GIF（5/10/15fps）；区域/全屏/窗口录制
- HUD：164×32、10pt 圆角、暂停/继续/停止；菜单栏可停止
- OCR：Vision 全语言（按系统支持列表），结果窗口可复制

### P9 本轮对照上游后的补齐

- 快门音（`CaptureSound`）：保存/复制时播放系统快门音，独立串行队列避免蓝牙设备卡顿
- 文件名模板（`FilenameFormatter`/`FilenameSanitizer`）：`{date} {time} {timestamp} {unix} {window} {app} {index} {random} {yyyy} {MM} {dd} {HH} {mm} {ss} {ms}`，`/` 分文件夹，200 字节截断，自动避让重名
- 保存策略生效：设置里的「保存文件 / 复制到剪贴板 / 快门音 / 悬浮缩略图」真正接入保存链路（此前只有开关没有行为）
- 悬浮缩略图（`FloatingThumbnailController`）：保存后右下角缩略图，点击进编辑器、拖出为文件、5 秒自动收起
- 选区增强：可编辑 W×H 尺寸框、三分构图网格、悬停窗口高亮、窗口边线吸附
- 工具条改为直接搬上游：`ToolbarStripView` / `ToolbarButtonView` / `ToolbarLayout` 与 `repositionToolbars()` 几何算法
  - 横向工具条：选区下方居中，间距 6pt；选项行（线宽/线型）在工具条下方 2pt
  - 竖向动作栏：选区右侧 6pt、与选区顶部对齐；空间不足时按上游规则推到左侧/下方
  - 32pt 按钮 + 4pt 内边距 + 6pt 圆角 + Flameshot 紫色选中态，不再使用自绘大黑条
- 交互性能：遮罩先显示、后台抓取冻结帧（自身窗口抓帧期间 `sharingType = .none`，抓完恢复）；吸附检测缓存
  `NSBitmapImageRep`，不再每次鼠标移动重建整张 2x 位图
- 权限：移除会阻塞主线程的窗口抓取探针；不再被 `CGPreflightScreenCaptureAccess` 误报拦住，只有真实抓图失败才提示
- 热键：注册失败（被 macshot 等占用）时每 2 秒重试，不再永久失去快捷键
- 标注增强：直线 / 荧光笔工具、实线-虚线-点线、Shift 约束（正方形/45°）、画笔移动平均 + Chaikin 平滑、自定颜色面板、文字字体选择、多行文字、真实单位测量（mm/cm/m 校准）、标注不透明度
- 编辑器增强：拖出文件手柄（拖出成 PNG、点击复制、Option 拖动窗口）、未保存关闭确认、方向键微调（Shift 10pt）、单键工具快捷键（v/r/e/l/a/p/m/t/n/x/b/h/d/z/g/i/c）
- 截图历史浮层（`CaptureHistoryOverlay`）：缩略图网格、双击 Finder、右键复制/OCR/钉图/删除
- OCR 结果窗口：识别语言切换重识别、字符数、自动复制提示
- 滚动截图：到底自动停止、HUD 显示帧数与停止按钮、两阶段重叠匹配、固定侧栏检测与平铺、去掉固定 6 帧上限（最多 25 帧）
- 录屏：MP4 直接写入 SCK 真实帧与真实 PTS（不再定时器采样 + 合成时间戳）；磁盘空间不足自动停止；系统休眠停止；3-2-1 录制倒计时
- 视频编辑器：多段剪切（时间线可视化）、0.5–4× 变速、字幕（可指定起止时间）、分轨音量、MP4 导出进度/取消、编辑器内导出 GIF
- 钉剪贴板内容：图片 / 文件 / RTF / HTML / 纯文本钉图

## 仍未移植（有意排除或受平台限制）

| 能力 | 原因 |
|---|---|
| 注册 / 登录 / 账号体系 | 用户明确不移植 |
| Sparkle 自动更新 | 用户明确不移植；由本仓库自行构建安装 |
| Google Drive / imgbb / S3 上传 | 需要账号、密钥或外部服务 |
| 翻译 30+ 语言 | 依赖在线服务 |
| 鼠标点击高亮 / 录制选区边框 | 已实现覆盖层，录屏是否包含覆盖层取决于 ScreenCaptureKit 捕获范围 |
| 可编辑光标 / 按键 HUD / 摄像头画中画 | 需要逐帧遥测与摄像头编码，尚未移植 |
| 视频缩放轨道 / 定格 / 视频打码 | 视频编辑器已支持剪切/变速/字幕，这三类轨道尚未移植 |
| 自动 PII / 人脸打码 | 需要额外 Vision 模型与规则，保留手动打码 |
| 添加截图 / 粘贴图片图层 / 0.1–8x 画布缩放 | 已实现图片标注图层与画布缩放 |
| 自定义图片印章 | 已移植完整 Emoji 目录（按 Unicode 属性生成 + 搜索），未做自定义图片印章 |
| macOS 窗口框 / 交通灯 / 30 种渐变 / mesh 渐变 | 已实现 30 种渐变与标题栏；mesh 渐变未做 |
| 跨屏拖选区域并拼接 | 已接入统一遮罩跨屏拖选 |
| Liquid Glass（macOS 26） | 本机 macOS 15，不引入仅 macOS 26 API |
