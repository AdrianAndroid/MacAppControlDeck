# PureMac 新 UI 设计方案

- 日期：2026-11-24
- 关联变更：`openspec/changes/archive/2026-11-24-add-puremac-ui-redesign-and-lemon-research/`
- 状态：已归档（v3 顶部页签方案已实施；v2 左轨方案未采用，保留供追溯）
- 目标窗口：PureMac 主窗口（`SystemToolWindowController`，默认 720×640，最小 640×520）

## 1. 背景

PureMac 模块第一版按「功能先跑通」交付：6 个页签、清理/卸载/大文件/重复文件/进程都能用，但界面是每页各写一套。用户复核后确认界面不达标，需要在回家后按统一信息架构重做。

本方案只改 UI 结构，不改清理引擎、安全边界、签名与权限。

## 2. 现状问题

1. 顶部横排 6 个页签，640pt 下拥挤，无导航强调条。
2. 每页各自实现标题、说明、操作、统计、脚注，间距 12/10/8/6 混用。
3. 扫描在页中上部、清理在底部状态栏、取消两处都有，视线来回跳。
4. 概览 6 张 108pt 卡片排 3 列，720pt 下每卡约 176pt，留白多，无磁盘主卡。
5. 空态占满整页，同时保留筛选、统计与脚注。
6. 窗口背景、卡片、表格三层灰，层级不清。

## 3. 参考与取舍

| 参考 | 采用 | 不采用 |
| --- | --- | --- |
| 上游 PureMac（SwiftUI 原生，侧栏导航） | 左侧栏 + 内容区 | Protection / App Updates 等未移植页 |
| macOS 系统设置、本项目设置页 | 相同侧栏视觉与宽度 | — |
| 活动监视器 | 双行表格、CPU/内存列、系统进程置灰 | 可拖拽列宽与多标签 |
| CleanMyMac 类工具 | PageHeader 主操作、FilterStrip、SummaryBar、危险分级 | 「一键智能清理」大按钮（与零选中契约冲突） |
| Apple HIG | 8pt 网格、字号阶梯、语义色、44pt 行高 | — |

## 7. 验收

1. 640 / 720 / 900 三档窗口截图，无横向或纵向溢出。
2. 6 个页签的空态、扫描中、有结果、清理中四态逐张核对。
3. 清理、永久删除、卸载、强退四个弹窗文案与可用性正确。
4. 关闭并重开窗口不崩溃；扫描结果按现有行为重置。
5. `swift build` 通过，`swift test --filter SystemToolTests` 全绿。

## 9. 柠檬复核后的 UI 定稿（v2，待实现）

依据 `Docs/research/2026-11-24-tencent-lemon.md` 第 11 节二次实操结论修订。相对第 4 节的三处关键调整：

1. **扫描中态**：柠檬用「当前路径 + 不定长进度条 + 取消（二次确认）」，不用百分比数字。v2 采用同样表达，取消走「进度丢失」二次确认。
2. **入口/空态**：柠檬的隐私、磁盘、大文件、重复、相似照片都是同一套「标题 + 副标题 + 单主按钮 + 插画」入口页。v2 把 PureMac 各页空态统一成这一形态（第 4.9 节三态里的「待扫描」）。
3. **进程/启动项行**：柠檬启动项的「状态胶囊 + 行内开关 + 展开箭头」表达更清晰。v2 在进程页给系统进程加状态胶囊，保留置灰。

**不借鉴**：首页广告条、柠檬精选外链、一键智能清理大按钮（与默认零选中冲突）。

## 10. 柠檬交互对齐版（v3，聚焦清理模块，基于现有顶部页签）

依据 `Docs/research/2026-11-24-tencent-lemon.md` 第 11 节复核结论，在**不改动现有顶部 6 页签导航**的前提下，把交互层对齐柠檬。与 v2 的差异：v2 主张改左侧栏；v3 保留现有页签，只动「入口 / 扫描 / 结果 / 确认」四层交互，改动面最小、不碰清理引擎与安全边界。

### 10.1 交互规律映射（柠檬 → PureMac）

| 柠檬实测交互 | PureMac 落地 |
| --- | --- |
| 功能入口页统一：标题 + 副标题 + 单主按钮 + 插画 | 各页空态统一为「入口卡」，去掉分散的筛选/统计/脚注 |
| 扫描态：当前路径 + 不定长进度条 + 取消，无百分比 | 状态栏与页内统一为路径进度，取消走二次确认 |
| 取消扫描二次确认「进度丢失，下次需重新扫描」 | 文案对齐，确认/继续两个按钮 |
| 结果态：分类 tab / 分组头 + 逐项勾选 + 未勾选时清理禁用 | 垃圾/大文件加分组折叠，清理按钮零选中时禁用 |
| 重复/相似照片先添加文件夹，扫描按钮禁用 | 重复文件先选扫描根，未选根时扫描按钮禁用 |
| 启动项状态胶囊 + 行内开关 + 展开箭头 | 进程/卸载加状态胶囊；系统进程保留置灰 |
| 不借鉴：广告条、精选外链、一键智能清理 | 保持默认零选中，不设"一键全清理"主按钮 |
