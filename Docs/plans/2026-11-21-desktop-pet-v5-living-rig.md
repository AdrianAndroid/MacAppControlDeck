# 桌面宠物 v5「Living Rig」详细开发计划

- 日期：2026-11-21
- 变更：`openspec/changes/add-desktop-pet-v5-living-rig/`
- 基线：v4 单帧场景（`add-desktop-pet-v4-raster-rig`，HEAD `6f19deb`）
- 目标：解决三件事 —— ① 去掉木桌、只留猫 + 键盘 + 鼠标；② 眼睛不再"各动各的"，变成共同注视一个点；③ 补齐落爪 / 按鼠标的姿态与生命感。
- 执行方式：一次跑完、中途不打断（沿用上一轮约定）。

## 0. 默认决策（如无异议即按此执行）

| # | 决策 | 选择 | 理由 |
|---|------|------|------|
| D1 | 猫身下缘 | **A：软阴影收口**，键盘在猫身前遮住下缘，无桌沿 | 去掉整张桌面，又不留横向截断线 |
| D2 | 键帽起点 | **从键盘对应键位升起**（不再从头顶后方） | 恢复"按键 → 键帽"的因果感 |
| D3 | 眼睛 | **完整方案**：3D 视线向量 + 每眼投影 + 眼睑眨眼 + 微扫视 + 高光随动 | "分开动"是结构问题，只调参数治不好 |
| D4 | 落爪 | **局部精灵 + 补洞**，不做整帧切换 | 唯一能同时有姿态又零双影的路 |

## 1. 问题清单与验收对应

| 现状问题 | 根因 | 本计划对应 |
|----------|------|------------|
| 两只眼"分开动" | 两张独立眼 PNG 各平移同一向量；素材本身不对称（左 60×57 / 右 68×61）；无共视点；无眼睑 | Phase 2 |
| 桌面突兀、像被截断 | scene 层含整张木桌，alpha 按"桌在底下"抠的 | Phase 1 |
| 没有落爪 / 按鼠标姿态 | 三关键帧不对齐，整场景混合双影 | Phase 3 |
| 键帽从头顶弹 | 槽位写死在设计坐标 y≈100–195 | Phase 4 |
| 整只猫是死的（只有头和眼动） | 单帧 scene 无任何局部层 | Phase 4（尾 / 耳 / 呼吸） |
| 打字时视线固定下压 0.22 | 未映射真实按键位置 | Phase 4 |

## 3. Phase 2 · 眼部系统重做（2.5 天）

### 2.1 数据结构

```swift
// 视线是整个系统的唯一真源
struct GazeVector { var x: Double; var y: Double; var z: Double }   // 归一化方向
struct EyeGeometry { var center: CGPoint; var radius: CGFloat }     // 每只眼自己的眼心与半径
struct EyeState { var pupilOffset: CGPoint; var lidClose: CGFloat; var highlightOffset: CGPoint }
```

每只眼的瞳孔偏移 = **球面投影**，不是共同平移：

```
d = normalize(gaze)                       // 与头部 yaw/pitch 一起被 head 变换修正
maxR = eye.radius * 0.42                  // 眼球可转半径
offset = maxR * (d.x, d.y) / (1 + 0.35 * d.z)   // 近处汇聚：z 越近偏移越小
```

- 两眼共用同一个 `GazeVector`，但用各自的 `EyeGeometry` ⇒ 视觉上"各走一点、始终看向同一点"。
- 头部 yaw/pitch 参与修正：`d' = R(yaw,pitch) · d`，抵消头转造成的眼眶滑动。
- `pupilRange` 上限仍 ±10 / ±6 pt（设计坐标），clamp 后做软限。

### 2.2 眼睑与眨眼

- 新素材 `lidL.png` / `lidR.png`：上眼睑，闭合状态能完整覆盖眼球（含虹膜）。
- 眨眼曲线：`close = 1 → 0` 用 `cubic-bezier(0.2, 0.9, 0.35, 1)`，总时长 110ms（闭 40 / 停 20 / 开 50）。
- 触发：随机 3–7s；打字高频时概率 ×1.6；进入睡眠时改为半闭 0.65 常驻。
- 双眼同步闭合（同一曲线相位），禁止两只眼各自不同步 —— 这是"分开动"的一个重要来源。

### 2.3 微扫视与高光

- 微扫视：每 1.2–3.5s 生成一次 ±0.08 的随机目标叠加到光标目标，弹簧 `stiffness 900 / damping 30`（快、脆），持续时间 < 180ms，然后回落到光标。
- 高光：`highlightOffset = -0.32 × pupilOffset`（相对眼球反向微移），保持"高光钉在光源方向"的质感。
- 提供 `--debug-gaze` 开关：窗口内画出视线向量与两眼投影点，便于验收。

### 2.4 头部

| 参数 | v4 | v5 |
|------|----|----|
| yaw | ±3° | ±6° |
| pitch | ±2.2° | ±3.2° |
| 弹簧 | 150 / 26 | 190 / 28（更跟手） |
| 延迟 | 无 | 40ms 视觉滞后（先眼后头） |

### 2.5 验收
- 光标从左到右快速横扫：两眼夹角始终 < 1.5°，不回出现"一只眼看左一只眼看向右"。
- 静止注视屏幕角落 30s：每 1.2–3.5s 有可察觉的微扫视，瞳孔不"钉死"。
- 眨眼 60 次目检：无穿帮、无眼白残留、双眼同相位。
- 头部 ±6° 不出现颈部露底（head 层与 body 层重叠 ≥ 14px）。

## 4. Phase 3 · 爪子姿态（2 天）

### 3.1 局部精灵 + 补洞

| 精灵 | 来源 | 处理 |
|------|------|------|
| `pawL` | 母版左前爪（键盘左侧） | 手绘 polygon 取 alpha，外扩 3px feather |
| `pawR` | 母版右前爪（键盘右侧） | 同上 |
| `patchL` / `patchR` | 爪后的"洞" | 用同层邻近的键盘面 / 身体面像素平移镜像贴回，30px feather 融边 |

补洞顺序：`body → patch(洞) → paw(精灵)`；`paw` 每帧按 `rest/down/mouse` 目标做 `translate + rotate + squash`。

### 3.2 动作表

| 触发 | 目标 | 时长 / 曲线 |
|------|------|-------------|
| 非重复 keyDown（左半区键） | `pawL` 下移 4px、squash 1.0→0.94、`keyboard` 该键位下沉 1px | 120ms ease-out，回弹 160ms |
| 非重复 keyDown（右半区键） | `pawR` 同上 | 同上 |
| 左右同时按 | 两爪同时 down，互不覆盖；身体 sink 1px 只算一次 | 同上 |
| 鼠标左/右键按下 | `pawR` 沿 160ms 曲线移到鼠标上方、`mouse` 下沉 4px、头偏 1.5° | 160ms in / 140ms out |
| 松键 / 松鼠标 | 回 rest，不做整猫换帧 | 160ms |

### 3.3 验收
- 连打 30s：两爪交替、无穿模、无"爪悬空"、无补洞色块闪动。
- 左右同时按 20 次：两爪都下去，身体只沉一次。
- 鼠标连点 10 次：右爪准确落在鼠标上，鼠标下压可见，无键帽生成。
- 2× 放大目检补洞区：接缝 < 1px 色差、无硬边。

## 5. Phase 4 · 生命感与因果（2 天）

### 5.1 尾巴与耳朵
- `tail` 层绕尾根 `pivot` 做 `±4°` 低频正弦（0.28Hz）+ 每 6–12s 一次快速甩尾（±9°，180ms）。
- `earL` / `earR` 独立层（从 head 反推，用 polygon 切）：每 8–20s 一次 60ms 抽动，幅度 6°；打字时概率 ×1.4。

### 5.2 呼吸
- `body` 层 `scaleY 1.0 → 1.008`、`translate y -1.5px`，周期 4.2s，绕键盘上沿为锚点；`head` 跟随 0.6 倍，不同步。

### 5.3 键帽与视线因果
- 槽位从"头顶后方"改为**键盘键位上方**：由 `PetKeyMap` 的键位坐标 → 键盘投影坐标 → 槽位（每键一个，超出 4 个取最近）。
- 键帽 `riseY` 90（2x 像素，约 45pt），升起曲线 0–90ms，悬浮 90–420ms，淡出 420–600ms。
- 打字时视线目标 = 该键位坐标（`gaze` 指向键位 + pitch 下压），不再固定 0.22。
- 视线恢复：松键后 500ms 回到光标。

### 5.4 验收
- 按键 `M`：视线落到 M 键、左爪下压、键帽从 M 键位升起、帽面字符 M。
- 尾/耳在静止画面中有可察觉的微动，但幅度不喧宾夺主（画面抖动 < 2px）。
- 呼吸周期内窗口内容不出现重采样模糊（用整数像素平移）。

## 8. 风险与对策

| 风险 | 概率 | 对策 |
|------|------|------|
| 补洞出现色块/硬边 | 中高 | patch 优先取同平面像素 + 30px feather；每日目检 2× 放大图；不行就降级为"爪从键盘后探出"（不露洞） |
| 眼睑素材与眼窝边缘不吻合 | 中 | 眼睑按眼窝 polygon 生成，坐标由 manifest 统一驱动；先做静态闭合比对图再上动画 |
| 尾/耳切割带出键盘或桌面像素 | 中 | 切割时用 `alpha ∩ bodyMask`，并锁 z 序在 body 之上、keyboard 之下 |
| ±6° 头转在颈部露底 | 中 | head/body 重叠补到 ≥14px；超限时自动降压到 ±4° |
| 30fps 多两层合成掉帧 | 低 | 图层预解码常驻；`Canvas(rendersAsynchronously: false)` 保持；必要时把 shadow/keyboard 预合成为一张静态底图 |
| 素材重做导致 v4 存档不可复现 | 低 | v4 资源目录保留不删，v5 用新目录 `Resources/v5`，manifest 版本号区分 |

## 9. 回滚

- 保留 v4 目录一个发布周期；矢量皮肤仍是最终兜底。
