# 桌面宠物 V2：参考视频复刻计划

- 日期：2026-11-21
- OpenSpec：`rebuild-desktop-pet-rig`
- 目标：把当前“趴卧贴纸猫”重做为参考视频中的“竖构图、完整蹲坐、目标驱动全身联动”的黑猫桌宠，并让五套皮肤共用同一套新骨架
- 原则：先骨架，后动作；先黑猫 1:1，再延展皮肤；不把录屏光标当成角色功能

## 1. 已确认的参考事实

| 维度 | 参考视频 | 当前实现 | 结论 |
|---|---|---|---|
| 姿态 | 臀部落座、后腿折叠、上身抬起、前肢下垂的蹲坐 | 横向趴卧，身体被裁成团 | 必须重做骨架 |
| 构图 | 约 300×430，竖版，耳尖到尾尖完整 | 约 480×280，横版，头占 2/3 | 窗口/画布要改竖版 |
| 头部 | 大绿眼、竖瞳、无鼻无嘴、黑耳内、细胡须 | 圆眼、粉鼻、嘴、粉耳内、粗奶油描边 | 重画脸部 |
| 身体 | 梨形躯干、髋、后腿、脚掌、长尾 | 无腰无髋无腿，短粗尾 | 补完整轮廓 |
| 前肢 | 细前臂 + 奶油色爪套；左爪搭白色小鼠标，右爪键盘 | 两个圆爪固定，5px 抬落 | 做肩肘腕 IK |
| 键盘 | 约身体 1.7 倍宽，30+ 高窄键，左右橙色键 | 小于头，约 12 列扁圆键 | 放大并重画 |
| 鼠标 | 键盘左侧白色小鼠标，带滚轮 | 奶油色大椭圆，位置/比例不对 | 缩到参考比例 |
| 键帽 | 每次按键弹出白色字母键帽，4–6 个堆叠，含 `⌘` | 只有四区粉色高亮 | 新增键帽队列 |
| 视线 | 打字时持续看键盘并先看向目标键；鼠标移动时看光标 | 只对鼠标做 ±12% 微偏移，打字不看键盘 | 新增视线仲裁 |
| 动作 | 肩→肘→爪、躯干前倾、髋部配重、尾巴反作用 | 呼吸/尾巴/耳朵各自正弦，爪位固定 | 改为目标驱动骨骼链 |

**不属于角色功能、不会实现**：录屏里的白色手势指针、30s 处巨大鼠标箭头、视频裁切造成的缺头/波浪键盘。

**暂定处理**：尾巴旁常驻的 `S` 键帽先作为静态装饰层保留，默认开启、可关闭；如果后续确认它是状态指示，再改语义。

## 2. 核心架构

```text
输入（cursor / keyDown / keyUp）
        │
        ├─ 视线目标：光标坐标 或 目标键坐标
        ├─ 手部目标：鼠标位置 或 键位落点
        │
        ▼
PetTargetArbiter（鼠标 / 打字 / 混合 / 休眠优先级）
        │
        ▼
PetRig（髋 → 脊柱 → 胸 → 颈 → 头；肩 → 上臂 → 前臂 → 爪；尾根 → 尾中 → 尾尖）
        │
        ├─ PetReachSolver：两段 IK + 可达范围 clamp
        ├─ PetSpringChain：每关节阻尼弹簧、预备/跟随/回弹
        └─ PetGazeSolver：眼球 + 头颈微转，远距离先转头再转眼
        │
        ▼
PetRenderer（分层绘制）
        │
        ├─ 尾/后腿 → 躯干 → 头/耳/胡须
        ├─ 鼠标 → 前肢/爪 → 键盘/键帽
        └─ 浮动键帽 / S 装饰在最上层
```

### 2.1 动作优先级

1. **键盘按下**：立即把视线目标锁到该键 120–220ms，爪子目标切到该键附近；鼠标移动暂不抢视线。
2. **持续打字**：视线保持在键盘区域，跟随当前键；松键后仍停留 300–600ms。
3. **鼠标移动**：无键盘输入时，视线锁光标；左臂/左爪驱动虚拟鼠标，身体重心轻移。
4. **鼠标 + 键盘同时**：右爪优先键盘，左爪保持鼠标；左半区按键时才让左爪短暂离鼠标，松键回位。
5. **空闲/睡觉**：鼠标移动或按键唤醒；睡眠中不做快速视线切换。
6. **手动暂停/安全输入/锁屏/录屏**：优先级最高，冻结目标并停止动画时钟。

### 2.2 键位与爪子

- 把键盘建成真实键位网格：行列、键宽、修饰键、橙色键都有坐标。
- 每个 keyCode 映射到唯一键位；取最近可达落点，不允许瞬移。
- 近键：小臂弯曲、身体轻微前倾；远键：肩部前送、躯干侧倾、髋部反向配重、尾巴反向摆。
- 左爪默认鼠标；右爪默认键盘右半区；左半区由左爪短时接管。
- 按下时键帽下陷 1–2pt，松开回弹；键盘整体允许 0.5–1° 的受力倾斜。

### 2.3 浮动键帽

- 显示真实的字母、数字、符号和 `⌘/⇧/⌥/⌃`，只存在于内存，不写日志。
- 每次 keyDown 生成一个键帽，位置从爪子附近弹到胸前固定槽位。
- 最多同时 6 个，旧的先淡出；生命周期约 1.2–1.8s，快速连打会堆叠。
- 动画：scale 0.7→1.08→1.0，轻微旋转，阴影随层级变化。
- 与视线、落爪、键下陷共用同一个 keyDown 时间戳，避免各做各的。

### 2.4 竖版尺寸与点击

- 先按参考外接框定基准，再重算三档，不再沿用横版数值。
- 建议基准（待渲染校准）：视觉约 240×340，窗口约 248×348；S/L 等比缩放。
- 以底部中心为锚点；切换尺寸时脚掌/键盘底边不跳。
- 点击路径只包含“身体轮廓 + 鼠标 + 键盘”，不包含胡须、尾巴外侧透明区和浮动键帽。
- 默认位置仍在 Dock 上方，但高度增加后要重新校准，避免压住 Dock。

## 3. 分阶段计划

### Phase 0：参考基线与验收样本
- 固定 12 个参考关键帧：idle、鼠标、抬手、眯眼、连打、单键、远键、修饰键。
- 记录姿态比例、头身比、键盘比例、键帽队列数量。
- 建立 V2 的 golden 截图基准，不先改 UI。
- 产出：参考帧索引、尺寸/比例表、验收清单。

### Phase 1：竖版画布与骨架
- 新建 `PetRig`：关节、父子关系、局部坐标、可动范围。
- 重算 S/M/L 视觉尺寸和窗口尺寸，底部中心锚点。
- 先只画骨架调试线，确认蹲坐轮廓、髋/后腿/尾根位置。
- 产出：骨架调试模式、竖版几何测试、尺寸/位置测试。

### Phase 2：黑猫视觉 1:1
- 重画头、耳、眼、胡须、躯干、后腿、长尾、前臂、爪套。
- 键盘放大到参考比例，30+ 键，左右橙色键；鼠标缩到白色小鼠标。
- 去掉厚奶油描边、粉鼻、嘴；黑猫改为纯黑剪影 + 细边缘光。
- 产出：黑猫 idle / 鼠标 / 打字三张黄金截图。

### Phase 3：视线与鼠标联动
- `PetGazeSolver`：光标/键位目标 → 瞳孔 + 头颈微转；远距离先转头。
- 鼠标模式：左臂/左爪跟随虚拟鼠标，身体重心轻移，尾巴反作用。
- 视线优先级与回退：打字压过鼠标，停手后回到光标。
- 产出：鼠标移动视频/帧序列、视线偏移测试。

### Phase 4：键盘落爪与键帽
- `PetKeyMap` 升级为真实键位网格；keyCode → 键位坐标/显示字形。
- 两段 IK 落爪 + 可达范围 clamp + 身体前倾/侧倾。
- 键帽队列、修饰键、堆叠、淡出；键下陷/回弹。
- 产出：连打 3/5/10 键的帧序列，键帽数量与生命周期测试。

### Phase 5：全身自然运动
- 每关节阻尼弹簧，加入预备、跟随、overshoot、squash & stretch。
- 打字时头随节奏点头、眼睛眯起、耳朵延迟、尾巴配重。
- 鼠标/远键时髋部与后腿支撑，避免“整只猫平移”。
- 睡眠/唤醒/摸头/点击头的状态过渡。
- 产出：动作曲线调试面板、慢放验收视频。

### Phase 6：窗口、尺寸与交互整合
- 竖版三档尺寸、点击穿透、轮廓缓存、位置保存、多屏 clamp。
- 拖拽、右键菜单、快捷键、内置操作、设置页实时预览。
- 无输入监控权限时的静态降级、Secure Input/锁屏/录屏暂停。
- 产出：实机三档尺寸、五皮肤、点击穿透验收。

### Phase 7：五套皮肤延展
- 黑猫作为基准，白猫、橘猫、三花、小狗共用新骨架。
- 每套只改配色、花纹、耳形/尾形等局部特征，不改骨架比例。
- 产出：5×3 渲染矩阵与皮肤切换截图。

### Phase 8：性能、测试与回归
- 单元测试：几何、IK clamp、视线仲裁、键帽队列、状态优先级。
- 性能：空闲 <2% CPU、持续打字 <8%、内存 <60MB；动作时 30/60fps 可配置。
- 隐私：不记录字符、不联网；键帽字形只在内存中存在。
- 产出：`swift test` 全绿、CPU/内存采样、权限降级录像。

### Phase 9：文档、归档与提交
- 更新 README、模块文档、截图、OpenSpec spec、tasks、归档摘要。
- 归档 `rebuild-desktop-pet-rig`，同步 `openspec/specs/desktop-pet/spec.md`。
- 构建、签名、覆盖安装，提交说明引用 change-id。

## 4. 验收硬线

- [ ] 三档尺寸都能看到完整耳尖、后腿、脚掌、尾巴尖，不被窗口裁切。
- [ ] 视觉外接框为竖版，宽高比约 0.65–0.8；头高不超过全高 35%。
- [ ] 黑猫无鼻无嘴、竖瞳、黑耳内；键盘宽度约为身体 1.6–1.8 倍。
- [ ] 鼠标移动时左臂/左爪有连续运动，眼睛锁定屏幕光标；不是只动眼珠。
- [ ] 任意 keyDown 后 100ms 内视线移向该键，150ms 内爪落到可达键位附近。
- [ ] 连打 5 键至少出现 3–5 个可读键帽，含修饰键时字形正确。
- [ ] 打字时头、胸、髋、后腿、尾巴至少三层可见联动，不是独立正弦叠加。
- [ ] 键帽不写日志、不联网；权限降级、锁屏、录屏、多屏行为不回归。
- [ ] `swift test` 全绿，空闲/连打 CPU 与内存达标。

## 5. 风险与处理

- **窗口变高**：默认位置可能压 Dock；Phase 1 就重算底部锚点与默认偏移。
- **五套皮肤工作量大**：先黑猫 1:1 通关，再批量调色；不并行改五套。
- **IK 不可达键**：允许“近似落点 + 身体代偿”，禁止瞬移或拉伸变形。
- **键帽隐私**：字形只存在内存和渲染层，不进入日志、不落盘、不发网络。
- **性能**：弹簧和 IK 只在有输入时跑 60fps，空闲降到 12fps；用采样数据决定最终帧率。
