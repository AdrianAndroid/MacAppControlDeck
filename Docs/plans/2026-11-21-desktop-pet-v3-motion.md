# 桌面宠物 V3 动作设计：从“弹簧橡皮管”到关节化小猫

## 参考结论

以 30fps 原视频逐帧分析，参考猫并不是靠一个位移弹簧完成动作，而是有明确关节层级和延迟：

| 项目 | 参考表现 |
| --- | --- |
| 换爪 | 2–3 帧完成，约 67–100ms；到键位后轻微下压 |
| 眼睛锁定 | 1–2 帧，约 33–67ms |
| 手臂稳定 | 4–5 帧，约 130–170ms，轻微过冲 |
| 键帽 | 按下当帧出现，停留约 0.45–0.6s，退场 2–3 帧；新键帽把旧键帽横向挤开 |
| 尾巴 | 大部分时间保持同一条大 C 弧，根到尾只有极小浮动；转向/连打时才短促甩一下 |
| 身体 | 只有很轻的重心侧移，头比身体慢半拍 |
| 边缘 | 细灰边缘光 + 底部阴影，不是均匀黑色硬描边 |

## 当前差异

1. 交互渲染只有 8fps，一帧 125ms，参考里 80ms 的动作表现不出来。
2. 手臂只有“肩→爪”两段弧线加粗描边，没有肩、肘、腕三级旋转，看起来像橡皮管。
3. 尾巴整条由同一个正弦值驱动，根到尾一起摆，弧度变化不合理。
4. 黑猫轮廓使用 1.7–1.8px 均匀描边，手臂外描边 8.2px，边缘像贴纸切边。
5. 键帽固定在 6 个槽位直接消失，没有参考里的滑轨挤压和运动模糊。
6. 白鼠标基准压到画布左边，滑动时会被裁切。

## 造型修正（第二轮，先于动作）

第一版对比板的中间和右边都不是新设计：中间是当前实现，右边只是把骨架线叠在当前图上。用户指出的颈缝、细手臂、无腿，正是当前实现的缺陷。新概念图见 `Docs/design/desktop-pet-v3-anatomy-concept.png`。

### 头身关系
- 头和身体必须共用同一条外轮廓路径，不能用“头部椭圆 + 身体椭圆”两个图形叠在一起。
- 头部下缘与脸颊直接融进肩膀，颈部没有内凹、没有内部描边、没有高光分界线。
- 头宽略大于肩宽，脸颊弧度承接肩线；头占全身高度约 45%，但不再显得“头浮在身体上”。

### 手臂
- 肩点藏在躯干轮廓内，肘部略微外翻，前臂近垂直落到键盘。
- 上臂明显粗于前臂：设计画布 260×360 下，上臂约 10px，前臂收到 7.5px，爪约 13px。
- 静止时手臂贴在身体前方，与躯干同为纯黑，只靠外轮廓的细灰边缘光分开；不能出现内部黑描边。

### 后腿
- 骨骼必须有髋 → 膝 → 踝 → 脚掌；参考里小腿大部分被键盘挡住，但脚掌一定要从键盘上方露出来。
- 两只圆脚左右分开，脚背各有一道浅趾缝；脚不能悬空，也不能被键盘完全盖住。
- 臀部比肩宽，形成稳定蹲坐的梨形重心。

### 尾巴
- 尾根固定在右侧臀部、右臂后方，先向下再向外卷成大 C 弧，不能从手臂上长出来。
- 尾巴整体粗、粗细均匀、末端圆润；静止时几乎不动。

## V3 动作蓝图

### 1. 手臂：三段关节 + 延迟链
- 骨骼：肩点（固定在躯干）→ 上臂 → 肘 → 前臂 → 腕 → 爪。
- 肘部使用独立角度弹簧，比爪目标慢 30–40ms；快速换键时肘先外翻，前臂再跟随。
- 上臂粗、前臂细：按上面的 10px → 7.5px → 13px 爪绘制，不再用一根等宽线。
- 落键：爪先到，腕部下沉 1–2px，按下瞬间轻微压扁，松键 80ms 回弹。
- 不可达键：先限制爪到可达圆，再让肩部前送、身体侧倾 2–3px。

### 2. 尾巴：5 节低幅链
- 节点：尾根固定 → 4 段尾骨 → 尾尖；每节只做小角度旋转。
- 静止：振幅 ±4px，周期 3–4s，根部几乎不动。
- 转向/打字：尾尖延迟 150–200ms 甩一次，幅度 10–14px，然后回位。
- 删除当前整条 `sin(2t)` 控制点平移。

### 3. 身体和头
- 身体侧倾由爪子位移的 30–40% 驱动，头部再延迟约 80ms。
- 打字时只轻点头 + 眯眼，不做整身正弦晃动。
- 保留呼吸，但幅度减半，避免“漂浮感”。

### 4. 节奏与帧率
- 输入当帧立即更新目标。
- 按键/鼠标移动触发 30fps 爆发 0.35–0.45s，之后 15fps 跟随，静止 2fps。
- 物理子步 2×，保证 30fps 下弹簧稳定。
- 键帽生命周期 0.5–0.55s，横向滑轨 120ms，最多 5 个。

### 5. 轮廓
- 黑猫取消整圈粗描边，改为左侧 0.8px 灰边缘光 + 底部柔和阴影。
- 耳朵、四肢末端做收细，肩部用同色圆片融合，避免“拼接感”。

### 6. 尺寸与鼠标
- 大 260×360（当前中号），中 208×288，小 166×230。
- 鼠标向画布内收 6px，滑动限制 ±3px；点击区同步。

## 素材路线评估

| 路线 | 自然度 | 五套皮肤 | 成本/风险 | 结论 |
| --- | --- | --- | --- | --- |
| 矢量骨架升级 | 70–85% 接近参考 | 保留 | 中，需重写手臂/尾巴/动作层 | 推荐先做 |
| Live2D 模型 | 最接近，参考很可能就是 Live2D | 每套皮肤需独立模型 | 高，要接 Cubism SDK、处理模型授权和内存 | 若矢量仍不达标再做 |
| PNG 序列帧素材 | 只有抬爪/落爪两态，形态接近原版 Bongo Cat，不是参考这只 | 可换色但动作少 | 低 | 不满足“自然”目标 |

公开可参考的开源项目：
- `ayangweb/BongoCat`：Apache-2.0 代码，Live2D 猫，支持键鼠跟随；模型素材授权需单独确认。
- `MMmmmoko/Bongo-Cat-Mver`：MIT 代码，图片播放器 + Live2D 播放器，0.1.4 之后未继续开源。
- CC0 猫精灵包（OpenGameArt / itch.io）大多只有走、跑、坐、睡，没有键盘/鼠标姿态，风格也不匹配。
