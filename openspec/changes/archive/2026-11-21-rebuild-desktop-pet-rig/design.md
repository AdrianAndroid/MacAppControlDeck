# 设计：参考视频 1:1 桌宠骨架与动作系统

## 1. 参考测量

- 参考宠物外接框约 `300×430`，宽高比约 `0.70`
- 头高约占全高 `25–30%`，当前约占 `65–70%`
- 键盘宽约为躯干宽 `1.7×`
- 键盘 30+ 列高窄键，左右各一颗橙色键
- 鼠标是键盘左侧白色小椭圆，带滚轮
- 连打时同时存在 4–6 个浮动键帽，含字母和 `⌘`
- 打字时瞳孔明显向下/向目标键偏，身体前倾，尾巴反向摆

## 2. 视觉分层

从后到前：

1. 尾巴（尾根 → 尾中 → 尾尖）
2. 后腿、脚掌
3. 躯干、腰、胸
4. 头部、耳、胡须
5. 鼠标
6. 上臂、前臂、爪套
7. 键盘、按键
8. 浮动键帽、`S` 装饰

这样可以做前臂遮挡键盘、爪压在键帽上、尾巴从身体后方穿出的关系。

## 3. 骨架

```text
root
└ hips
  ├ spine → chest → neck → head → ears
  ├ tailRoot → tailMid → tailTip
  ├ thighL → shinL → footL
  └ thighR → shinR → footR

chest
├ shoulderL → upperArmL → forearmL → pawL
└ shoulderR → upperArmR → forearmR → pawR
```

每个关节有：

- 局部位置、旋转、缩放
- 可动范围与阻尼弹簧
- 目标权重，用于 IK/视线叠加
- 调试线开关

## 4. 目标与仲裁

`PetTargetArbiter` 统一产出：

- `gazeTarget`: 光标屏幕坐标 / 当前键位坐标 / 睡眠默认点
- `leftPawTarget`: 鼠标面中心 / 左半区键位 / 休息点
- `rightPawTarget`: 右半区键位 / 休息点
- `headTarget`: 视线目标的头颈微转
- `bodyLean`: 目标距离与左右偏移

优先级：

1. 暂停/锁屏/安全输入/录屏
2. 键盘按键（120–220ms 锁定，防鼠标抢视线）
3. 鼠标移动
4. 空闲呼吸
5. 睡眠

键盘按住期间持续保持目标；keyUp 后 300–600ms 回退。鼠标与键盘同时存在时，右爪归键盘，左爪保持鼠标；左半区按键短时接管左爪。

## 5. 视线

- 屏幕坐标转换到桌宠局部坐标，clamp 到头部可视角。
- 目标近：只动瞳孔。
- 目标远/偏：先转头 3–8°，再补瞳孔偏移。
- 打字：瞳孔锁定键位，快速连打做 80–120ms saccade，不瞬移。
- 打字时抑制随机眨眼，改为眯眼；停手 1s 后恢复眨眼。
- 鼠标离开屏幕/窗口太远时，瞳孔停边缘，头保持朝向。

## 6. 手臂 IK

- 两段 IK：肩→肘→腕，腕目标由键位坐标 + 爪半径得到。
- 可达范围 clamp：超出臂长时，肩/胸/髋共同前送，而不是拉长手臂。
- 落爪提前量：keyDown 前 1–2 帧开始移动，keyDown 当帧压到键面。
- 按住：爪保持，键下陷；keyUp：回弹 + 轻微 overshoot。
- 空闲：右爪回键盘休息位，左爪回鼠标；不回固定旧坐标。

## 7. 键盘与键帽

- 键位表：`row/column/x/y/width/height/label/modifier`。
- 每键有 `pressDepth`，按压缩 1–2pt，释放弹簧回位。
- 键盘整体按受力方向倾斜 0.5–1°，远键时更明显。
- 键帽队列最多 6 个，生命周期 1.2–1.8s。
- 键帽位置按槽位堆叠，从爪边弹入，旧键帽先淡出。
- 修饰键字形：`⌘ ⇧ ⌥ ⌃`；字母/数字/符号按 keyCode 映射。
- 键帽字形仅在内存，不写日志、不落盘。

## 8. 全身运动

- 每个关节用临界阻尼弹簧，目标变化时自然跟随。
- 打字节奏驱动胸/头小点头，幅度随 KPM 增大。
- 远键时躯干侧倾、髋部反向、后腿支撑、尾巴反向摆。
- 鼠标快速移动时，左臂滞后 1–2 帧，眼睛先到。
- 睡眠：胸腹呼吸变慢、头下沉、耳朵放松、尾巴停摆。
- 摸头/点击头：先眯眼，再歪头，再回正；不覆盖手动暂停。

## 9. 尺寸与窗口

- 基准视觉 `240×340` 左右，窗口 `248×348` 左右（待骨架校准）。
- S/L 等比缩放，底部中心锚点；脚掌、键盘底边不跳。
- 点击路径 = 身体 + 鼠标 + 键盘轮廓；不含胡须、尾巴外侧、浮动键帽。
- 默认位置仍 Dock 上方，高度增加后重新测偏移。
- 透明、置顶、不抢焦点、隐藏释放 runtime 不变。

## 10. 测试

- 几何：竖版尺寸、锚点、多屏 clamp、hit path。
- 视线：鼠标/键位坐标转换、优先级、回退时间。
- IK：可达/不可达 clamp、无瞬移、爪落点误差。
- 键帽：队列上限、生命周期、修饰键字形。
- 动作：关节弹簧收敛、无 NaN、pause 不覆盖。
- 渲染：黑猫 idle/鼠标/打字 golden；5×3 矩阵。
- 性能：空闲/连打 CPU、内存、帧率。

## 11. 风险

- 竖版窗口更高，可能压 Dock；Phase 1 先校准。
- 五套皮肤重画成本高；先黑猫通关。
- IK 复杂键位不可达；允许身体代偿，禁止拉伸。
- 60fps 动作可能超出 CPU 预算；有输入才升帧，空闲降帧。
