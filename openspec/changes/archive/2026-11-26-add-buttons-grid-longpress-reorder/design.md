# 设计：按钮卡片网格与长按拖动排序

## 布局

```text
┌ 按钮 ─────────────────────────────────────────────┐
│ [＋ 添加按钮 ▾]                    [搜索按钮…]     │
│                                                    │
│ 应用 · 4                                  [收起]   │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐        │
│ │  icon  │ │  icon  │ │  icon  │ │  icon  │        │
│ │ Safari │ │ Xcode  │ │ 终端   │ │ Figma  │        │
│ │ 应用   │ │ 应用   │ │ 应用   │ │ 应用   │        │
│ └────────┘ └────────┘ └────────┘ └────────┘        │
│                                                    │
│ 快捷操作 · 5                              [收起]   │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐        │
│ │   ⌘C   │ │   ⌘V   │ │   ⏎    │ │  内置  │        │
│ │ 复制   │ │ 粘贴   │ │ 回车   │ │ 截图   │        │
│ │ 快捷   │ │ 快捷   │ │ 快捷   │ │ 内置   │        │
│ └────────┘ └────────┘ └────────┘ └────────┘        │
│                                                    │
│ 点击选中；按住 0.5 秒后拖动排序；右键可编辑        │
└────────────────────────────────────────────────────┘
```

- 外层一个 `ScrollView`，内部 `LazyVStack(pinnedViews: [.sectionHeaders])`，分组标题吸顶。
- 分组标题使用窗口底色而不是半透明材质，滚动时不透视下方卡片。
- 每组 `LazyVGrid`，固定 4 列；内容区约 560pt。
- 卡片约 128×118pt，图标 40pt，名称最多两行。
- 设置窗口 840×640，与现有布局一致。

## 交互分配

| 操作 | 结果 |
|---|---|
| 点击卡片 | 选中，不执行按钮 |
| 长按 0.5 秒 | 卡片浮起，进入拖动准备态 |
| 准备态后移动 > 4pt | 拖动排序 |
| 松手 | 一次落位，写回 `sortOrder` |
| 右键 | 重命名、编辑组合、上移、下移、删除 |
| 底部操作条 | 重命名、删除、编辑组合 |

状态机：

```text
按下卡片
  ├─ 立即选中
  ├─ 0.5s 内移动 > 8pt → 取消准备，不排序
  └─ 按住 ≥ 0.5s 且位移 ≤ 8pt
        ├─ 松手 → 退出准备，保持选中
        └─ 移动 > 4pt → 拖动排序
```

长按只负责拖动，不再负责弹菜单，避免“长按后是菜单还是拖动”的二选一。

## 拖动落位

拖拽时只渲染本地预览顺序，不写配置；松手调用一次 `moveToIndex`。
指针离开本组卡片区域或进入另一组时，浮层显示红色不可放置边框，不显示插入空隙；松手直接取消。

```text
拖动前： [A] [B] [C] [D]
拖动 C 到 B 前：

[A] [   ] [B] [D]     ← 本地插入空隙
     ┌──────┐
     │  C   │          ← 跟手浮层
     └──────┘

松手：   [A] [C] [B] [D]
```

`ButtonGridReorder.targetIndex(pointer:frames:order:)` 以当前分组卡片中心为基准，找最近卡片，指针在中心左侧插到该卡片前，否则插到后。返回的是“移除拖动项后”的目标 index，正好匹配 `moveToIndex` 的语义。

## 长列表

- 单页纵向滚动，不嵌套滚动。
- 总数超过 12 个显示搜索框；搜索时禁用拖拽，只保留点击选中与右键编辑。
- 分组标题可收起/展开，收起后只显示标题和数量。
- 第一版不做边缘自动滚动；长列表可先用滚轮滚到目标附近，再长按拖动。

## 无障碍兜底

- 右键菜单提供上移/下移，不依赖长按拖动。
- 选中后底部操作条提供重命名/删除。
- 卡片保留 `contextMenu` 与辅助功能标签。
