# 提案：全局快捷键默认全部关闭

## Why

上一版默认启用全部全局快捷键。F1 与键盘亮度键、其他截图/录屏软件冲突，用户还得逐项关闭。默认不抢任何按键更安全：需要哪个再打开。

## What Changes

- 首次安装（无 `hotkeys.json`）：总开关保持开启，但所有快捷键默认**关闭**，不注册 Carbon 热键。
- 「恢复默认」与「全部恢复默认」：组合还原，同时把快捷键置为关闭。
- 旧配置一次性迁移：读取到没有 `shortcutsOffByDefault` 标记的文件时，把所有快捷键改为关闭并写回标记；组合保留。
- 设置页显示「当前没有任何全局快捷键生效」，并说明默认关闭策略。
- 单条「恢复默认组合」仍只改组合，不改单项开关。

**非目标**：

- 不改变总开关语义；它仍是全部快捷键的总闸。
- 不自动替用户打开任何入口。

## Capabilities

### Modified Capabilities

- `global-hotkeys`：默认关闭、重置即关闭、旧配置迁移。

## Impact

- 代码：`GlobalHotKey.swift`、`GlobalHotKeys.swift`、`HotKeySettingsView.swift`。
- 用户可见：升级后 F1 / ⌘⇧X / ⌃⌥D / ⌃⌥P 默认都不再响应，需在设置里逐项打开。
- 测试：新增默认关闭、迁移、单项重置用例。
