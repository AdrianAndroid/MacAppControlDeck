# Design: 副屏倒计时单一布局与动图轮播

## 1. 单一布局 + 二分缩放

```
基准（--cd-scale: 1）：图标 6.8u | 标签 1.7u / 数字 4.8u / 小字 1.6u | 剩余环 4.8u
cdFit()：scale 从 1.0 往 0.6 二分 7 次，选取「卡片、数字、小字都不裁切且高度 <= 可用高度」的最大值
判据：card.scrollWidth / #cdTime.scrollWidth / #cdMeta.scrollWidth 均不超过自身 clientWidth
      card.offsetHeight <= 列高 - 月历高 - 组间距
到 0.6 仍不成立才隐藏整张卡（例如竖屏且未开启显示）
```

## 2. 剩余语义

| 位置 | 文案 |
| --- | --- |
| 环 | 剩余比例弧长，中心 `剩 72%`（短写，避免环内挤） |
| 小字 | `还剩 72% · 21:00 下班` |
| 已下班 | 数字绿色正计时，环 `visibility:hidden`，小字 `10:00 上班 · 10:30 下班` |

## 3. 三层节奏（全部由时钟推导）

```js
场景序号 = (floor(今日秒数 / 300) + 当前小时) % 12      // 5 分钟一换，每小时整体错位一位
微变化   = floor(今日秒数 / 45) % 3                    // --cd-speed: 0.88 / 1.06 / 0.96
插播     = 剩余比例首次跨过 50 / 25 / 10 时，强制显示对应场景 30s（充能 / 整理 / 沙漏）
```

未上班、已下班各只有一个场景，不参与轮播。

## 4. 切换实现

```
两个绝对定位的 .cd-layer 叠在 .cd-icon 内，交替写入并切 .on：
  旧层 opacity 1→0、scale 1→0.94；新层 opacity 0→1、scale 0.94→1，各 400ms
reduced-motion：transition: none（硬切），只在场景变化时换内容
页面隐藏：clearInterval；回前台 loadCountdown() 重新取数并按当前时钟落到正确场景
```

## 5. 验收

```
480×320   → scale ≈ 0.70，无裁切、无横向溢出
844×390   → scale ≈ 1.00
1440×900  → scale ≈ 1.00，数字升到 5.6u
500×900   → 默认隐藏（竖屏）
已下班    → 绿色正计时、环隐藏
```
