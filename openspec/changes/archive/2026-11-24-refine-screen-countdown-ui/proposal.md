# Change: 副屏倒计时改为单一布局 + 剩余语义 + 12 场景轮播

## Why

上一版用 `full / slim / line / hidden` 四档切换排版，同一块屏幕在不同宽度下会长得不一样；进度写成「已工作 72%」，读起来是「又过去一点」，和「盼下班」的心理反着；左侧只有一个动图，盯着看 10 分钟就腻。

## What Changes

1. **只保留一套布局**：删掉三档结构差异，卡片永远是「图标 | 标签 / 数字 / 小字 | 剩余环」；放不下时用二分法把整张卡片等比缩到 0.60–1.00，元素不增不减。
2. **全部改成剩余语义**：环画剩余比例、中心 `剩 72%`、小字 `还剩 72% · 21:00 下班`；已下班显示 `已下班` 正计时、环隐藏。
3. **动图轮播（14 个场景）**：工作中 12 个（走时键盘 / 咖啡勺子 / 沙漏 / 整理文件 / 打字文稿 / 充能进度 / 转笔 / 撕日历 / 打印纸 / 灯泡 / 耳机音符 / 盆栽），未上班 1 个（咖啡热气），已下班 1 个（门口小人），后两者不轮播。
4. **三层节奏 + 事件插播**：场景每 5 分钟（对齐整点 5 分、每小时错位一位）、微变化每 45 秒（动画速度 0.88/1.06/0.96）、剩余 50% / 25% / 10% 时插播对应场景 30 秒。
5. **切换格式**：400ms 交叉淡入 + 1.00→1.03 微缩放，双层 SVG 容器轮换；`prefers-reduced-motion` 硬切；页面隐藏暂停、回前台按当前时钟直接落到正确场景。
6. 所有节奏常量集中为 `CD = { sceneEvery, microEvery, milestoneHold, milestones }`。

## Capabilities

- `remote-web-panel`：副屏倒计时的布局、语义与动图轮播规则。

## Impact

- 只改 `Panel/ScreenHTML.swift`（CSS/HTML/JS）与 `ScreenHTML.version`；Swift 侧状态机与接口不变。
- 无新增依赖、无位图；14 个场景合计约 25 KB 内联 SVG。
- 设置页与 `/api/screen/countdown` 字段不变；无新增用户可见入口（沿用副屏+设置 → 副屏）。

## Non-goals

- 不做工作日/节假日区分（仍每天同一套时间）。
- 不做竖屏独立布局（默认隐藏，打开时同一张卡片缩比）。
