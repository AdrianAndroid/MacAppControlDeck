# system-cleaner 变更（add-menubar-netspeed）

## ADDED Requirements

### Requirement: 菜单栏实时网速与独立状态项

PureMac SHALL 在菜单栏以三个独立状态项分别显示 CPU、内存与实时网络速度（用户选择可分别点击与单独开关，因此不采用柠檬的紧凑合栏形态），网速以两行分别显示上行与下行速率，单位按量级为 K/s 或 M/s。

#### Scenario: 状态项显示

- **WHEN** 用户启用 CPU、MEM 或实时网速中的至少一项
- **THEN** 菜单栏出现对应的独立状态项，各自可单独点击（点击均打开 PureMac 窗口，MEM 项后续改为弹出内存菜单，见 add-menubar-memory-menu）
- **AND** 网速项以两行显示：第一行为上行（↑），第二行为下行（↓），单位按 K/s / M/s 量级切换
- **AND** 各列数值完整不被菜单栏边缘裁切，整体垂直居中并跟随系统深浅色；按 macOS 从右往左的排列规则反序创建，使从左到右呈现 CPU → MEM → 网速

#### Scenario: 网速定宽与统一样式

- **WHEN** 网速速率数值位数变化（如 `17.0` → `336.0`）
- **THEN** 网速状态项宽度恒定、左右边界不移动，数值小数点对齐（figure space U+2007 右对齐填充 + 等宽数字字体 + 固定列宽）
- **AND** ↑上行 / ↓下行两行同字号（9pt）同颜色（跟随系统 `.labelColor`），只靠箭头方向区分，不出现双字号或双色

#### Scenario: 网速采样

- **WHEN** 模块启用、网速开关打开
- **THEN** 系统以公开 API 读取活动网络接口的累计收发字节，定时差分得到上下行速率
- **AND** 累计值回绕或接口重置时速率记 0，不出现负数
- **AND** 采样过程不申请任何 TCC 权限、不依赖第三方依赖或私有 API

#### Scenario: 指标开关

- **WHEN** 用户在设置中关闭某一指标（CPU / MEM / 实时网速）
- **THEN** 对应独立状态项移除，其余指标保持显示
- **AND** 三者全部关闭时三个状态项全部消失
