# Change: 副屏月历下方增加每天下班倒计时

## Why

副屏被当成桌面表盘时，最有价值的信息是「今天还要上多久班」。现在月历的 5 行格子用 `1fr` 撑满整列，下方留白浪费；把行高压到上限后可以在月历栏底部放一个倒计时卡，不占用时钟栏和天气栏。

## What Changes

1. 月历行高封顶：`.grid { max-height: calc(5 × 5.6u) }`，行高随 `--u`（vmin × 小/中/大档位）缩放，不再写死 px。
2. 月历栏底部新增倒计时卡：左侧动态图标、右侧「距下班 04:33:12」+ 小字目标与进度；默认显示秒。
3. 每天按同一套时间计算，不区分工作日/节假日（后续再加）：
   - 现在 < 上班时间 → 未上班，倒计时到上班
   - 上班时间 ≤ 现在 < 下班时间 → 工作中，倒计时到下班
   - 现在 ≥ 下班时间 → 已下班，正计时到当天 24:00
   - 下班时间 ≤ 上班时间 → 视为跨夜班
4. 时间状态由 Swift 计算并通过 `GET /api/screen/countdown` 下发，页面只做倒数与到点重取，避免两份时间逻辑漂移。
5. 适配四档：`full`（图标+数字+目标行）/ `slim`（去目标行）/ `line`（单行）/ `hidden`，由 JS 按月历栏剩余高度判定；竖屏默认隐藏，可在设置打开为单行。
6. 设置 →「副屏」新增「下班倒计时」卡：开关、上班时间、下班时间、显示秒、竖屏也显示、实时预览；改动通过 `ScreenEventHub` 立即推送页面刷新。
7. 动效：工作/未上班用 SVG 呼吸与热气 3 帧、已下班用跑动 3 帧，全部 CSS keyframes 内联，`prefers-reduced-motion` 时冻结。

## Capabilities

- `remote-web-panel`：副屏月历栏新增下班倒计时与相应配置。

## Impact

- 新增 `Modules/RemoteControl/OffWorkCountdown.swift`（配置 + 纯函数状态机 + 快照）。
- 改 `Server/APIRouter.swift`（新路由）、`Panel/ScreenHTML.swift`（版本 `2026-11-24.1`）、`UI/ScreenSettingsView.swift`。
- 新增 `OffWorkCountdownTests`；副屏页面不新增依赖、不引入图片资源（全部内联 SVG）。
- 用户数据仍在 UserDefaults（`screen.offwork.*`），升级不清空。
- 无新增独立窗口，入口沿用现有「设置 → 副屏」；内置操作无需新增（R0 不适用）。

## Non-goals

- 不做工作日/法定节假日区分（先每天一致，节假日后续单独变更）。
- 不做午休扣除、按天计薪、月度统计。
- 不改变时钟栏与天气栏的任何布局。
