# Design

持久化桌宠类型，共用现有透明浮窗、输入监听和生命周期；设置用 TabView 切换，旧设置迁移为 BongoCat。KeyCat 通过非持久化 WKWebView 加载固定版本的本地场景，使用 360:368 原始画面比例，并将现有物理按键、鼠标与光标送入上游行为状态机。KeyCat 的 raycast 命中结果控制透明区域穿透、头部摸头与身体拖动，切换或隐藏时清理输入及定时器；不引入第二个事件监听器。窗口禁用 SwiftUI 自适应尺寸，以保留预留边距。

KeyCat 上游未提供项目级许可证，其 README 限定个人及内部使用；公开分发前须取得授权。three.js 的 MIT 许可证随资源保留。
