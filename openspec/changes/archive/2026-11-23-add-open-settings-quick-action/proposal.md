# 提案：新增「打开设置」内置快捷操作

## Why

设置窗口目前只能从菜单栏或 ⌘, 打开；手机面板和快捷操作区没有直接入口。把「打开设置」做成内置操作后，可以从按钮管理添加，并在菜单栏快捷操作与手机面板触发。

## What Changes

- `BuiltinActions` 新增预设：`settings.open`，名称「打开设置」，符号 `⚙`。
- 执行时调用 `MenuBarController.shared.openSettings()`，在 Mac 上打开设置窗口。
- 该按钮可像其他内置操作一样从「设置 → 按钮 → 添加内置操作」添加，并自动出现在菜单栏快捷操作与手机面板快捷操作区。
- 升级后首次启动自动补一个「打开设置」按钮（仅一次），用户删除后不再加回。
- 手机点击时仍然在 Mac 上打开设置，不向手机下发任何配置。

**非目标**：

- 不新增手机端远程修改设置的接口。
- 不改变设置窗口本身的布局与标签页。

## Capabilities

### Modified Capabilities

- `remote-key-actions`：新增「打开设置」内置操作。

## Impact

- 代码：`Control/BuiltinActions.swift`。
- 测试：内置操作预设注册。
- 用户可见：多一个可添加的快捷操作按钮。
