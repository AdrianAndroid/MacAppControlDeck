# 提案：远程快捷操作（桌面切换 / 快捷键）

## Why

目前手机面板只能启动或激活应用。日常遥控 Mac 时还频繁需要两类操作：**左右切换桌面空间**和**发送常用快捷键（复制、粘贴、F1–F12 等）**。每次都要起身操作键盘，破坏「手机即遥控器」的体验。本机实测已确认 CGEvent 键盘注入可用（复制/粘贴链路验证通过），Ctrl+←/→ 可切换桌面，具备实现基础。

## What Changes

- 按钮模型扩展为两类：**应用按钮**（现有）与**快捷操作按钮**（新增）。二者共用同一配置存储、同一 API 与面板，但语义不同。
- 快捷操作支持：
  - **预设清单**：桌面左 / 桌面右（Ctrl+←/→）、复制（⌘C）、粘贴（⌘V）、全选（⌘A）、撤销（⌘Z）、回车、Esc、F1–F12。
  - **自定义按键组合**：Mac 端「录制」实际按键，或用修饰键（⌘⌃⌥⇧Fn）+ 按键下拉**拼凑**组合（与应用选择同样的交互方式）。
- 手机面板**分组展示**：「应用」与「快捷操作」两个区域，各自独立排序。
- Mac 端「添加按钮」拆分为「添加应用按钮…」与「添加快捷操作…」；快捷操作按钮支持重命名、编辑组合、排序、删除。
- API `/api/activate` 语义扩展为「触发按钮」：同一端点、仍只接受按钮 ID；服务端按键型路由到快捷键注入，不新增可执行任意脚本的能力。
- 权限与失败反馈：注入需要辅助功能权限；未授权、处于安全输入模式（密码框）或以安全方式失败时，如实返回原因，不谎报成功。
- 存储兼容：旧 `buttons.json` 无类型字段视为应用按钮，平滑升级。

**非目标（本变更不做）**：多键序列（如 ⌘K ⌘S）、长按连发、文本宏输入、任意脚本/命令执行。

## Capabilities

### New Capabilities

- `remote-key-actions`：快捷操作按钮的模型（预设/自定义组合）、按键注入执行、权限检查与失败反馈、桌面空间切换。

### Modified Capabilities

- `button-panel-config`：按钮模型新增类型与组合字段；预设与自定义组合的增删改查与排序；旧配置兼容迁移。
- `lan-api`：`/api/activate` 扩展为触发任意按钮类型；响应结构补充快捷操作语义；仍只接受按钮 ID。
- `remote-web-panel`：面板分组展示（应用区 / 快捷操作区），动作按钮使用组合符号与图标呈现。

## Impact

- 代码：`Model/Models.swift`（按钮模型与组合结构）、`Store/ConfigStore.swift`（持久化与迁移）、`Control/AppControl.swift` 或其新增兄弟 `Control/KeyInjector.swift`（CGEvent 注入和权限检查）、`Server/APIRouter.swift`（路由）、`UI/MainWindowView.swift`（添加快捷操作、组合编辑/录制）、`Panel/PanelHTML.swift`（分组与展示）。
- 权限：依赖现有「辅助功能」授权（无新增系统权限）。
- 兼容性：`buttons.json` 向后兼容；API 请求格式不变，响应字段向后兼容。
- 风险：注入按键受「安全输入」限制；F1–F12 的实际效果取决于系统「将 F1、F2 用作标准功能键」设置；桌面切换依赖系统快捷键未被用户改键。
