# 提案：横屏副屏改为三栏，月历不再被挤扁

## Why

横屏时天气、月历、3 天预报都堆在右侧一栏，月历 6 行网格被压到 25px 左右行高，数字挤成一团；3 天预报还被底部控制条遮挡。竖屏下时钟在开天气时仍占 48% 高度，底部预报会顶出屏幕。

## What Changes

- 横屏且开启天气时，`.stage` 改为三栏网格：**时钟 | 月历 | 天气**。
- 月历独占中间整列高度，行高回到 45–60px；月份标题按列宽（`vw`）缩放，窄横屏不再压到天气栏。
- 天气栏垂直排列：今日天气在上，3 天预报在下，逐条显示「标签 + 图标 + 天气文字 + 高低温」。
- 3 天预报补上天气文字（此前只有图标与温度）。
- 竖屏开天气时时钟收窄到 40%，给底部预报留出空间。
- 大屏（`min-height: 700px`）限制月历网格高度，保持接近方形的单元格并居中。
- 页面版本提升到 `2026-11-23.7`。

**非目标**：

- 不改变时钟绘制、天气接口与数据模型。
- 不引入新的横屏尺寸档位；三档尺寸仍可用。

## Capabilities

### Modified Capabilities

- `remote-web-panel`：副屏横屏三栏布局与 3 天预报文字。

## Impact

- 代码：`ScreenHTML.swift`、`APIRouterTests.swift`。
- 用户可见：横屏月历不再挤在一起，3 天预报显示晴/少云等文字，竖屏预报不再被裁掉。
