# 设计：桌宠底部快捷图标栏

## 1. 为什么是独立窗口

桌宠面板本身要按轮廓做点击穿透、要响应键鼠、要跟随视线，往里塞交互控件会同时污染命中测试与动画状态。所以用 **独立的 borderless NSPanel**：

- `level = .floating`、`canJoinAllSpaces`、`fullScreenAuxiliary`，和桌宠一起跨空间显示
- `isOpaque = false` / `backgroundColor = .clear`，胶囊之外的区域完全透明
- `NSHostingView` 承载 SwiftUI，窗口尺寸与位置全部由 `PetDockCenter.relayout()` 计算

## 2. 尺寸：条宽收缩并居中

```
图标少（内容 < 桌宠宽）            图标多（内容 > 桌宠宽）

      ┌──────────────┐           ┌────────────────────────┐
      │ ▣ ▣ ▣ ▣ ▣ ▣  │           │ ▣ ▣ ▣ ▣ ▣ ▣ ▣ ▣ ▣ ▣ ▣  │→ 拖动滚动
      └──────────────┘           └────────────────────────┘
   ← 居中于桌宠窗口 →             ← 撑满桌宠窗口宽度 →
```

- `contentWidth = n × tile + (n-1) × spacing + paddingX × 2`
- `dockWidth = min(petWidth, contentWidth)`
- `x = pet.minX + (petWidth - dockWidth) / 2`，`y = pet.minY - height`（间距 0）

早期版本固定「条宽 = 桌宠窗口宽」，图标少时右侧留一大片空胶囊，看起来像破了一个洞；收缩 + 居中后视觉上才是一条真正的 Dock。图标数量变化由 `DeckState.$buttons` 订阅触发重排，按钮清空则直接隐藏。

## 3. 手势：为什么去掉 Button

最自然的写法是每格一个 `Button`，但那会吃掉拖动：`Button` 自己消费了按下/拖动事件，只有格子之间的 2px 缝能拖，实际上没法滑动。

最终改为 **整条一个 `DragGesture(minimumDistance: 0)`**：

- `|translation.width| < 3` 视为点击 → 松手时用 `startLocation.x` + 当前偏移反算出第几格，命中才执行
- `≥ 3` 视为拖动 → 只改 `offset`，`clampedOffset(maxScroll)` 保证不越过两端，松手归零拖动态、不触发惯性
- 悬停态改由 `onHover` 维护 `hoveredID`，不再依赖 Button 的按压外观

代价：拖动与点击共用一条手势，判定阈值必须严格（3px），否则手抖会把点击吃掉。

## 4. 视觉：一层胶囊 + 悬停反馈

第一版每个图标下还有一层 10% 白圆角底，在浅色/褐色壁纸上比图标本身还抢眼，并且和外层胶囊形成「双层卡片」。

改为：

| 元素 | 规格 |
| --- | --- |
| 外层胶囊 | `black 22%` + `white 8%` 1pt 描边，圆角 10 |
| 单格默认 | 无底 |
| 单格悬停 | `white 12%` 圆角（`tile × 0.24`）+ `scale 1.06`，150ms easeOut |
| 图标分离 | `black 28%` 2pt 圆角投影（去掉底框后防止浅壁纸糊成一团） |
| 运行绿点 | 5.5pt，附 0.8pt 深色描边，浅色图标上也能看见 |
| 最近点击 | 整体 `opacity 0.45`，退出即恢复 |
| 内边距 | 上下 6pt（决定条高），左右 4pt（比上下略小，贴边紧凑） |
| 图标尺寸 | 小 30 / 中 36 / 大 42，间距 2pt（鼠标操作，不需要防误触留缝） |

## 5. 排序与「不跳位」

`PetDockStats` 按 bundleID 存点击时间戳（每应用最多 40 条），分数 = `Σ 0.5^(age / 半衰期)`；冷却期内再 ×0.4。冷却只影响分数，**不再**让一批图标同时变淡（早期版本那样会让人以为图标坏了）。

重排时机被刻意限制为三个：首次出现、点击后空闲 5 秒、改设置。点击瞬间不重排，避免鼠标还停在原位置时图标跳走。

## 6. 生命周期

`PetPanelController` 在 `show / hide / shutdown` 和每次窗口位置/尺寸变化时调用 `syncDock()`；快捷栏自己不再持有定时器，运行绿点由视图内 3 秒 `Timer.publish` 刷新，应用退出后 `clearLastClickedIfNotRunning()` 清掉变浅标记。

## 7. 放弃的方案

- **5 格/页 + 左右箭头 + 页点**：在 30–42pt 的图标下，箭头和页点占掉的宽度足够再放两个图标，且鼠标用户对"翻页"没有直觉。
- **桌宠贴底时自动抬高宠物**：会改动桌宠窗口位置，破坏「底部中心锚点」的不变量，并让缩放/拖动测试失败。改为裁掉即可。
- **每格一个 Button**：见第 3 节，无法拖动。
