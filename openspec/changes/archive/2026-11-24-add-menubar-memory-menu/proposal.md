# Change: MEM 菜单栏状态项增加「内存占用」下拉菜单

点击菜单栏的 MEM 独立状态项时，不再只是打开 PureMac 主窗口，而是弹出一个内存占用下拉菜单，
形态参考腾讯柠檬：顶部显示总内存占用百分比，下面按内存占用列出正在运行的应用及其占用大小，
每行带「关闭」按钮可直接退出该程序，底部提示「关闭将直接退出程序，请先保存重要数据」。

## Why

三个状态项拆分后用户希望各项有独立交互。MEM 项最能提供即时价值：无需打开主窗口即可看到
哪些应用在吃内存，并能一键退出。对齐柠檬已验证的交互形态。

## What Changes

- MEM 状态项点击弹出 `NSMenu`（CPU / 网速项保持点击打开主窗口）。
- 菜单内容：内存占用百分比标题 + 按内存降序的运行中应用（图标 / 名称 / 占用大小 + 关闭按钮）+ 底部安全提示。
- 「关闭」按钮复用现有进程页的安全策略：仅允许退出 `/Applications` 与用户主目录下的应用，
  系统 / root / 受保护进程不可退出；调用 `NSWorkspace.terminate()`。
- 菜单在点击时即时采样一次进程内存，不常驻额外后台任务。

## Capabilities

### Modified Capabilities
- `system-cleaner`：新增 MEM 状态项的内存占用下拉菜单与一键关闭应用要求；复用其进程内存采样与安全退出策略，不新增权限。MEM 菜单属于 PureMac（system-cleaner 模块）的一部分，不单列新能力。

## Impact

- 改动集中在 `SystemToolModule.swift`（MEM 项点击行为 + 菜单构建）与新增一个菜单数据源。
- 零 TCC 权限、不改签名 / Bundle ID；不影响清理引擎与安全边界。
