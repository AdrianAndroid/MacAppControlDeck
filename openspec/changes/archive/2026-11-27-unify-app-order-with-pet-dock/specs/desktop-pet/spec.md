# desktop-pet 变更（unify-app-order-with-pet-dock）

## MODIFIED Requirements

### Requirement: 快捷栏点击频率排序

快捷栏 SHALL 使用与手机主屏共用的排序服务：支持「点击频率 / 手动顺序 / 最近使用」三种排序，默认点击频率；点击统计、半衰期与冷却全进程只维护一份。

#### Scenario: 频率排序

- **WHEN** 排序方式为点击频率
- **THEN** 按 `Σ0.5^(距今天数/半衰期)` 降序排列，冷却期内权重 ×0.4，同分按设置原顺序
- **AND** 手机与桌宠任一端点击都进入同一份统计

#### Scenario: 不跳位

- **WHEN** 点击图标后
- **THEN** 当前位置保持不变，只在空闲 5 秒、快捷栏重新显示或改设置时按新排序重排
- **AND** 手机端使用同一份顺序快照，不会各自算出不同结果

#### Scenario: 手机点击联动

- **WHEN** 用户在手机上点击某个应用
- **THEN** 桌宠快捷栏的「最近点击」变浅同步到该应用
- **AND** 5 秒空闲后两端一起按新顺序重排
