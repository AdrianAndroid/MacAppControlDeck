# Change: 横屏四模块加边框 + 月历行距 + 强度设置

## Why

横屏三栏内容全贴在纯黑背景上，模块边界靠留白猜；月历 5 行行距过密，看着「挤在一起」。用户希望给时钟 / 月历 / 倒计时 / 天气各自一块框，并能在设置里调边框强度。

## What Changes

1. 横屏：时钟、月历、倒计时、天气各自成框（1px 边框 + 2.4u 圆角 + 内边距 0.9u/1.3u），栏间距 2.4u → 1.6u。
2. 月历行距 `row-gap 0.9u`（竖屏 0.5u），行高上限 30u/42vh（大屏 34u/46vh）。
3. 新增外观设置：`screen.frame.enabled`（默认开）+ `screen.frame.strength`（默认 0.16，0–0.30 滑块）；设置 → 副屏 →「外观」；拖动即时生效。
4. 新接口 `GET /api/screen/frame` 下发 `{enabled, strength}`；页面用 `--frame-strength` 控制边框透明度，监听 `screen/events` 实时刷新。
5. 竖屏不画外框（避免窄屏碎片化），但行距与卡片面板生效。
6. 加框带来约 20px 高度损耗：天气列内部行距收紧（小时条/预报/更新行），保证不压出框外。

## Capabilities

- `remote-web-panel`（修改）：副屏横屏模块边框、月历行距与边框强度设置。
