# desktop-pet Delta

## MODIFIED Requirements

### Requirement: 桌宠底部快捷图标栏

桌宠 SHALL 在所有皮肤下方显示快捷图标栏，来源为手机 Deck 的「应用」按钮；单行排列，不分页、不带箭头与页点。

#### Scenario: 显示与跟随

- **WHEN** 桌宠可见、快捷栏开启且至少有一个应用按钮
- **THEN** 桌宠窗口正下方（间距 0）出现快捷栏，位置随桌宠移动/缩放更新
- **WHEN** 桌宠隐藏 / 全屏避让 / 快捷栏关闭 / 无应用按钮
- **THEN** 快捷栏一起隐藏；增删应用按钮时条宽与居中位置立即重算

#### Scenario: 点击

- **WHEN** 点击某个应用图标（按下到松开位移 < 3px）
- **THEN** 执行与手机面板相同的激活动作，并记录一次点击
- **AND** 该格显示运行中圆点（若开启），并作为「最近点击」变浅

#### Scenario: 横向拖动

- **WHEN** 在快捷栏上长按横向拖动（位移 ≥ 3px）
- **THEN** 只移动内容视口，不触发点击、不改变图标顺序、松手即停不带惯性
- **AND** 条宽取「图标内容宽度」与「桌宠窗口宽度」的较小值：图标少时收缩到内容宽度并相对桌宠窗口水平居中，图标多时撑满桌宠窗口宽度
- **AND** 超出不换行、不缩小；左右边缘 16pt 渐隐提示还有内容
- **AND** 内边距：上下各 8pt（撑满条高，图标垂直居中，运行圆点完整显示），左右各 4pt（比上下略小，贴边紧凑）

#### Scenario: 视觉

- **WHEN** 未悬停任何图标
- **THEN** 图标直接浮在半透明胶囊上，没有单格底框（胶囊 22% 黑 + 8% 白描边）
- **WHEN** 悬停某一格
- **THEN** 该格出现 12% 白圆角底并放大到 1.06（150ms），移开即恢复
- **AND** 图标带 2pt 柔和投影；运行中绿点带深色描边且不被裁切；「最近点击」的图标透明度 0.45
