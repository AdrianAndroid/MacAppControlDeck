# 变更提案：add-desktop-pet-v6-full-body-rig

## Why

v5「Living Rig」虽然把场景拆对了（去桌面、分层、键帽按真实键位），但用户实机验收判定「整体不协调、不像一只活的小动物」：

1. **动作振幅被单位拖死**：所有位移都在 720×960 设计坐标系里取小值，最终整体缩到 0.4 倍——瞳孔只走 2.2pt、爪只走 1.2pt、尾巴 1.9pt、键帽只升 8.8pt，全部低于可见阈值。
2. **只有末端在动，没有近端**：v5 没有上臂 / 前臂 / 躯干 / 肩这几层，按键只是「爪平移 3px」，所以是「脚趾抖一下」而不是整只猫一起动。
3. **素材按最小可行抠**：键盘底边靠硬切、鼠标细节被模糊磨平，放大 2 倍即露馅。

用户明确：**不怕改动大，要整体协调、生龙活虎**；动作数量可以少，但每一个动作必须是全身参与。

## What Changes

- **资产重做（P0）**：keyboard / mouse / cat 三张独立母版分开出图、分开抠，不再从「带桌子的整图」硬抠；键盘不裁底边、鼠标不 blur。
- **解剖分层（P1）**：猫切成 12 层——头、双耳、颈补片、躯干（含臀腿）、上臂 L/R、前臂+爪 L/R（各带关节盖）、尾巴两段；爪不再是独立平移层，而是前臂末端。
- **骨链 + IK（P2）**：键位坐标 → 肩 → 肘 → 爪心两段解析 IK；躯干倾斜、肩下沉、颈低头、耳后压、尾反相摆全部由落点驱动。
- **运动语法（P3）**：按「屏上 pt」定振幅（瞳孔 ±14pt、爪落 12–18pt、上臂 ±14°、尾尖 ±10pt），再 ×2.5 反算回设计坐标。
- **键帽（P4）**：升起 34pt（现在 8.8pt）、字号 12pt、生命 0.8s。
- 渲染器 `PetV5Renderer` 升级为 `PetRigV6`，v5 / v4 / 矢量逐级回退保留。

## Capabilities

- `desktop-pet`：新增「全身骨骼与 IK 落键」「按屏上振幅定标的运动语法」「独立母版资产与干净抠图」三条能力；MODIFIED「局部爪子姿态」为「整臂 IK 落键」。

## Impact

- 代码：`Sources/MacAppControlDeck/Modules/Pet/`（新增 `PetRigV6.swift`、`PetBoneIK.swift`，改 `PetRasterRig.swift` 分发、`PetStateMachine.swift` v6 tick、`PetTypes.swift`）。
- 资产：新增 `Resources/v6/`（12 层 + manifest），v5 目录保留一个发布周期。
- 文档：README 桌宠章节、`Docs/design/desktop-pet-v6-layer-spec.md`、`Docs/archive/`。
- 非目标：不做「每个键一张整猫图」（状态空间爆炸 + 多帧一致性无解）；不做整帧视频序列；不改窗口/权限/点击穿透逻辑；不新增打开入口（沿用 `pet.open`）。
