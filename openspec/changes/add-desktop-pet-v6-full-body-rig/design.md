# 设计：add-desktop-pet-v6-full-body-rig

## 1. 目标

把 v5 的「局部微动」换成「全身骨骼驱动的单一连续运动系统」：任意一次按键/移动，都必须同时体现在肩、上臂、前臂（爪）、躯干、颈/头、耳、尾上，且每个可感知位移在 288pt 窗口里 ≥ 3pt。

## 2. 分层（12 层 + 3 张场景层）

| 层 | 内容 | 支点 / 骨 | 允许自由度 |
|----|------|----------|-----------|
| `shadow` | 键盘下接触阴影 + 猫身前缘淡影 | — | 静态 |
| `keyboard` / `mouse` | 独立母版抠图 | — | 鼠标可下沉 |
| `torso` | 躯干含臀腿 | `hip (450,1250)` | 绕 hip 倾斜 ±3°、`scaleY 0.994–1.006`、`translateY ±2px` |
| `upperArmL/R` | 上臂 | `shoulderL (398,1128) / shoulderR (702,1128)` | 旋转 ±18° |
| `forearmL/R` | 前臂 + 爪（一体） | `elbow`（由 IK 解出） | 旋转 ±25° |
| `shoulderCapL/R` / `elbowCapL/R` | 关节盖毛发补片 | 跟随对应骨 | 随父骨 |
| `neck` | 颈补片 | 跟随头 | 随头转 |
| `head` | 头（含口鼻） | `neck (450,962)` | yaw ±8°、pitch ±4° |
| `earL/R` | 双耳 | 各自耳根 | ±5° + 后压 4° |
| `tail1/2` | 尾巴两段 | `tailRoot (905,1215)` | 段1 ±5°，段2 滞后 ±7°（相位差 0.18s） |
| `iris/pupil` | 眼 | 眼心 | 瞳孔 ±35 设计 px（≈ ±14pt） |

绘制顺序：`shadow → keyboard → mouse → torso → tail1 → tail2 → shoulder* → upperArm* → forearm*(含爪) → keycaps → neck → head(耳+眼)`。

## 3. 骨链与 IK

```
S = shoulder（随躯干倾斜后重算）
L1 = |S - E0|        上臂长，常量
L2 = |E0 - P0|       前臂长，常量
T = 目标爪心 = K(x,y) + (0, -28)   // 设计 px，压在键面上
```

两段解析 IK（余弦定理）：

```
d = clamp(|T - S|, |L1-L2|+1, L1+L2-1)
a = (L1² + d² − L2²) / (2·L1·d)      → 上臂相对 S→T 的夹角 θ1
b = (L2² + d² − L1²) / (2·L2·d)      → 前臂相对 T→S 的夹角 θ2
上臂方向 = dir(S→T) ± θ1  （取"肘朝外"的解）
前臂方向 = dir(T→S) ∓ θ2
```

三级兜底（够不到时依次）：上臂额外摆 +6° → 躯干前倾 2° → 肩点下沉 6px 并重解。

爪心命中后：`pawPress` 再由「爪心与目标距离」驱动 squash，不再单独平移。

## 4. 动作 → 全身分工

| 触发 | 躯干 | 肩 | 上臂 | 前臂/爪 | 颈/头 | 耳 | 尾 |
|------|------|----|------|--------|-------|----|----|
| 左区按键 | 左倾 2.5° | 左沉 3px | −14° | IK 落到键位 + 压 4px | 低头 3°、yaw −2° | 后压 4° | 反相 −3° |
| 右区按键 | 右倾 2.5° | 右沉 3px | +14° | 同上 | 低头 3°、yaw +2° | 后压 4° | +3° |
| 双键 | 前倾 2° | 双沉各 3px（不叠加） | ±14° | 双爪 | 低头 5° | 后压 6° | 滞后叠加 |
| 光标 | 随视线 ±3° | 微跟随 5% | 静息 | 静息 | yaw ±8° / pitch ±4° | 顺视线 | 反相 ±6° |
| 鼠标按下 | 右倾 3° | 右沉 4px | +10° | IK 落到鼠标上方 | 低头 4° | 前压 | 停摆 |
| 呼吸 | scaleY / 4.2s | — | — | — | 相位滞后 0.9s | — | ±3° 慢摆 |

弹簧统一：`stiffness 210 / damping 26`（比 v5 的 190/28 更"有劲"），按压释放用 `damping 18`（回弹更利落）。

| 躯干倾 | ±3° | ±3° |

## 6. 资产（P0）

三张独立母版：`keyboard` / `mouse` / `cat`，各自纯色背景独立出图，抠图按「背景色差 + 最大连通块 + fill_holes + 1px 羽化」，**不允许 blur > 1px、不允许裁底边**。统一 1440×1920 画布，锚点：键盘前沿线 `y = 1400 + 0.0146x`、双爪印中心。

## 7. 回退

`PetRigV6`→`PetV5Renderer`→v4→矢量，任一必需层缺失整体降级，不混搭。

## 8. 偏离记录（交付后回填）

原计划「两段解析 IK（肩 → 肘 → 爪心）」在实现时放弃，实际采用**单骨前臂 + 肩轴旋转 + 有界 push/slide 跟列**：

1. 母版里前臂是一整块连续毛皮（爪子与上臂在同一条轮廓里，肘关节处没有可切的褶皱），硬切成两段再相对旋转，接缝处会出现断层与「断臂」感——这比 v5 的「爪原地抖」更差。
2. 该宠物只做「小手在键盘上按」这一类动作，落点差异在 ±32 设计 pt 以内；肩轴旋转 + 横向平移已能让爪压到目标键列，实机截图上肉眼可辨。
3. 放弃 IK 后不再有「爪心误差 ≤ 2px」的硬指标，改在 spec delta 里写成「跟列 + 旋转」的实际契约；若将来引入带肘关节的母版（或把前臂拆成两段素材），可按本文第 3 节原方案恢复 IK。

其余偏离：键盘 / 鼠标母版改为 `image_gen + transparent` 直接生成（原计划的「从合成母版抠」在底边与滚轮缝上无法达标）；`torso` 保留整只猫真实像素而不是补毛填充（多边形扩散填充会露出浅色块）。
