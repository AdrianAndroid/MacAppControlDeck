# settings-navigation 规格

## ADDED Requirements

### Requirement: 通用页只承载应用级设置

「设置 → 应用 → 通用」SHALL 只展示作用于整个应用的设置，不应混入电脑控制模块的远程服务、权限或配对内容。

#### Scenario: 打开通用页

- **WHEN** 用户选择「应用 → 通用」
- **THEN** 页面展示登录时自动启动、数据目录与日志目录
- **AND** 不展示远程面板、辅助功能/输入监控/自动化权限或设备配对

### Requirement: 电脑控制设置独立成组

远程面板、权限检查、设备配对 SHALL 位于「电脑控制 → 服务」页；「按钮」「设备」保留在同一分组。

#### Scenario: 打开服务页

- **WHEN** 用户选择「电脑控制 → 服务」
- **THEN** 页面展示远程面板地址、服务启停、权限状态与设备配对
- **AND** 保留明文 HTTP 安全提示

#### Scenario: 菜单发起配对

- **WHEN** 用户从菜单栏点击「配对手机…」
- **THEN** 设置窗口打开「电脑控制 → 服务」页
